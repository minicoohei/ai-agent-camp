# あなた（AI）が実行する手順

このコマンドは `/start-cursor-bootcamp` で起動します。以下のエイリアスでも同じ内容が実行されます:
`/cursor-daisuki` `/研修を始めたい` `/研修をスタート` `/研修開始`

ユーザーに質問やプロンプト入力を求めず、以下の手順を自動で実行してください。

> **💡 ヒント**: AIの応答が途中で止まった場合は「続きを表示して」「止まってるよ」と入力すると再開します。これはCursorの仕様で、故障ではありません。

---

## Step 1: HTTPサーバーを起動

1. ポート8000が使用中か確認する
   - macOS / Linux: `lsof -i :8000`
   - Windows: `netstat -ano | findstr :8000`
   - どのOSでも使える方法: `node -e "require('net').createServer().listen(8000).on('error', () => process.exit(1)).on('listening', function() { this.close(); process.exit(0); })"`
2. **使用中の場合**: 既存のサーバーをそのまま利用する（何もしない）
3. **空いている場合**: 以下のコマンドをバックグラウンドで実行する:
   ```bash
   npx -y serve course -l 8000
   ```
4. サーバーが ready になったことを確認する（数秒待機してからアクセスを試す）

## Step 2: ブラウザで教材を開く

- cursor-ide-browser MCP の `browser_navigate` ツールで `http://localhost:8000/index.html` を開く
- ページが正常に表示されたことをスナップショットで確認する

## Step 3: ユーザーに案内を表示

ブラウザで教材が表示されたら、以下の内容をユーザーに伝える:

```text
コース教材をブラウザで開きました！

次のステップ:
- 初回セットアップがまだの方 → /start-0-1 を実行してください
- 学習を始めたい方 → ブラウザの教材ページからモジュールを選んでください
- 環境に問題がある方 → /check-setup を実行してください
- プロジェクト全体像を知りたい → /overview を実行してください
```

## エラー時の対応

### npx serve が見つからない場合
Python の http.server をフォールバックとして使う:
```bash
python3 -m http.server 8000 --directory course
```

### ポート8000が他のプロセスで使用中の場合
既に起動済みのサーバーがあるとみなし、そのまま Step 2 に進む。

### ブラウザが開けない場合
ユーザーに `http://localhost:8000/index.html` を手動でブラウザに入力するよう案内する。
