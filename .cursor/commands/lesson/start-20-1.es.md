# Lesson 20-1: Integración con Freee/MoneyForward - Introducción

## Lo que hará en esta sesión

Aprenda a obtener y operar datos contables utilizando el **servidor MCP de Freee**.

> **Note**: Esta lección está en preparación. El contenido se añadirá en el futuro.

## Requisitos previos

- Tener una cuenta de Freee
- Tener el servidor MCP de Freee configurado (configurado en `.mcp.json`)

## Objetivos

1. Configuración de autenticación del servidor MCP de Freee
2. Obtener y verificar datos de transacciones
3. Obtener la lista de cuentas contables
4. Operar datos de facturas
