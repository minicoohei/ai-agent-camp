# Lesson 23-1: LINE 公式アカウント運用 入門

## このセッションでやること

**Cloudflare Workers** と **LINE Messaging API** を使い、自社でコントロールできる LINE 公式アカウント運用基盤の構成を学びます。

## 前提条件

- LINE 公式アカウントと LINE Developers アカウントを用意できること
- Cloudflare アカウントを持っていること
- 必要に応じて `/setup-line-harness` を先に実行すること

## ゴール

1. LINE Developers Console、Webhook、シークレット管理の全体像を理解する
2. auto-register パターンで既存友だちを取り込む考え方を確認する
3. 自動応答、シナリオ配信、ブロードキャストの使い分けを説明できる
4. D1、line-harness MCP、Slack ブリッジの運用ポイントを確認する
