# Lesson 24-1: Salesforce CLI 連携 入門

## このセッションでやること

**Salesforce CLI (`sf`)** を使って、ブラウザログイン、SOQL でのデータ取得、CSV 一括更新、メタデータ retrieve/deploy の基本を学びます。

## 前提条件

- Salesforce 組織にログインできること
- `sf` CLI を利用できること
- 必要に応じて `/setup-salesforce` を先に実行すること

## ゴール

1. `sf org login web` と alias 管理の流れを確認する
2. `/module-24-soql` で Account / Opportunity を検索する
3. CSV を使った insert / update / upsert の考え方を理解する
4. `/module-24-metadata-retrieve` と `/module-24-metadata-deploy` の流れを確認する
