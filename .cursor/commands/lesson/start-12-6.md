# 🎓 Lesson 12-6: 要約の作成とコメントの返信

## 📍 このセッションでやること

**Lesson 12-6: 要約の作成とコメントの返信** へようこそ！

| 項目 | 内容 |
|------|------|
| ゴール | Notionページ/DBの内容をAIで要約し、コメント機能でチームコラボレーションを行う |
| 所要時間 | 約25分 |
| 使うスキル | ncli (Notion CLI) |
| 前提条件 | Lesson 12-5 完了（ページ更新ができる状態） |

**このセッションの流れ:**
1. ページ/DB内容の取得
2. AIによる構造化要約の生成
3. 要約をNotionページとして保存
4. コメントの投稿
5. コメント一覧の確認と返信ワークフロー

セッション終了時には、AIを使ったNotionコンテンツの要約作成とコメント機能による非同期コラボレーションができるようになっています。

> **💡 ヒント**: AIの応答が途中で止まった場合は「続きを表示して」「止まってるよ」と入力すると再開します。

## 🚀 Step 1: ページ/DB内容の取得

**AskQuestionの設定例:**
```json
{
  "title": "🚀 Step 1: コンテンツの取得",
  "questions": [{
    "id": "step_action",
    "prompt": "このステップをどうしますか？",
    "options": [
      {"id": "practice", "label": "このまま進める"},
      {"id": "review", "label": "例だけ確認する"},
      {"id": "skip", "label": "スキップする"}
    ]
  }]
}
```

**AIが実行すること:**

1. 要約対象のコンテンツを受講者に確認:
   - 「要約したいNotionページまたはデータベースのURLを教えてください」と案内
   - 前のレッスンで作成したページやDBでも、既存のコンテンツでも可

2. ページの場合 — 全コンテンツを取得:
   ```bash
   ncli fetch <ページURL>
   ```

3. データベースの場合 — 全レコードをJSON形式で取得:
   ```bash
   ncli db query <DB-URL> --json
   ```

4. 取得結果のボリュームを確認:
   - ページの場合: ブロック数、文字数の概算
   - DBの場合: レコード数、プロパティ数

5. 取得した生データの概要を受講者に共有する。

**期待される結果**: 要約対象のコンテンツが取得され、データのボリュームが把握できる。

## 🚀 Step 2: AIによる構造化要約の生成

**AskQuestionの設定例:**
```json
{
  "title": "🚀 Step 2: AI要約の生成",
  "questions": [{
    "id": "step_action",
    "prompt": "このステップをどうしますか？",
    "options": [
      {"id": "practice", "label": "このまま進める"},
      {"id": "review", "label": "例だけ確認する"},
      {"id": "skip", "label": "スキップする"}
    ]
  }]
}
```

**AIが実行すること:**

1. Step 1 で取得した内容をAIで分析し、構造化要約を生成する。

2. ページの場合の要約テンプレート:
   ```markdown
   # ページ要約: [タイトル]

   ## 概要
   - （1-2文で内容の概要を説明）

   ## 主要なポイント
   1. （重要なポイント1）
   2. （重要なポイント2）
   3. （重要なポイント3）

   ## 詳細セクション
   | セクション | 内容サマリー |
   |-----------|-------------|
   | セクション1 | ... |
   | セクション2 | ... |

   ## アクションアイテム
   - [ ] （発見されたタスクやTODO）

   ---
   *要約生成日時: YYYY-MM-DD HH:MM*
   *ソースページ: [URL]*
   ```

3. データベースの場合の要約テンプレート:
   ```markdown
   # DB要約: [タイトル]

   ## 統計サマリー
   - 全レコード数: X件
   - ステータス別: ...
   - 期間: YYYY-MM-DD 〜 YYYY-MM-DD

   ## カテゴリ別分析
   | カテゴリ | 件数 | 割合 |
   |---------|------|------|
   | ... | ... | ...% |

   ## 注目すべき項目
   - （期限が近いタスク、優先度が高い項目など）

   ## 推奨アクション
   1. （データに基づく提案）
   ```

4. 生成した要約を受講者に表示し、内容の正確性を確認してもらう。

**期待される結果**: コンテンツの構造化要約が生成される。

## 🚀 Step 3: 要約をNotionページとして保存

**AskQuestionの設定例:**
```json
{
  "title": "🚀 Step 3: 要約ページの保存",
  "questions": [{
    "id": "step_action",
    "prompt": "このステップをどうしますか？",
    "options": [
      {"id": "practice", "label": "このまま進める"},
      {"id": "review", "label": "例だけ確認する"},
      {"id": "skip", "label": "スキップする"}
    ]
  }]
}
```

**AIが実行すること:**

1. Step 2 で生成した要約をNotionページとして保存:
   ```bash
   ncli page create --title "AI要約: [元ページタイトル]" --body "<要約内容>"
   ```

2. 元のページの子ページとして保存する場合:
   ```bash
   ncli page create --title "AI要約: [元ページタイトル]" --parent <元ページURL> --body "<要約内容>"
   ```

3. パイプ入力で長い要約を保存:
   ```bash
   echo "<要約テキスト全文>" | ncli page create --title "AI要約: [タイトル]" --parent <元ページURL> --body -
   ```

4. 保存されたページを確認:
   ```bash
   ncli fetch <作成された要約ページURL>
   ```

5. Notionブラウザでも確認し、フォーマットが正しく反映されているか確認するよう案内する。

**期待される結果**: AI要約がNotionページとして保存され、ブラウザで閲覧できる。

## 🚀 Step 4: コメントの投稿

**AskQuestionの設定例:**
```json
{
  "title": "🚀 Step 4: コメントの投稿",
  "questions": [{
    "id": "step_action",
    "prompt": "このステップをどうしますか？",
    "options": [
      {"id": "practice", "label": "このまま進める"},
      {"id": "review", "label": "例だけ確認する"},
      {"id": "skip", "label": "スキップする"}
    ]
  }]
}
```

**AIが実行すること:**

1. ページにコメントを投稿:
   ```bash
   ncli comment create <ページID> "AI要約を生成しました。内容を確認してください。"
   ```

2. より詳細なコメントを投稿:
   ```bash
   ncli comment create <ページID> "レビューメモ:
- 要約は正確です
- セクション2の詳細を追加することを推奨します
- 期限が近いタスクが3件あります"
   ```

3. 要約ページにもコメントを追加:
   ```bash
   ncli comment create <要約ページID> "この要約は $(date +%Y-%m-%d) に自動生成されました。元ページに変更があった場合は再生成してください。"
   ```

4. コメントが投稿されたことを確認する。

**補足**: Notionのコメントはページレベルで追加されます。特定のブロックへのインラインコメントとは異なります。

**期待される結果**: ページにコメントが投稿される。

## 🚀 Step 5: コメント一覧の確認と返信ワークフロー

**AskQuestionの設定例:**
```json
{
  "title": "🚀 Step 5: コメント確認と返信",
  "questions": [{
    "id": "step_action",
    "prompt": "このステップをどうしますか？",
    "options": [
      {"id": "practice", "label": "このまま進める"},
      {"id": "review", "label": "例だけ確認する"},
      {"id": "skip", "label": "スキップする"}
    ]
  }]
}
```

**AIが実行すること:**

1. ページのコメント一覧を取得:
   ```bash
   ncli comment list <ページID>
   ```

2. 各コメントの情報を整理:
   - コメントID
   - 投稿者
   - 投稿日時
   - コメント内容

3. コメント一覧をテーブル形式で表示:

   | # | 投稿者 | 日時 | コメント |
   |---|--------|------|---------|
   | 1 | (あなた) | YYYY-MM-DD | AI要約を生成しました... |
   | 2 | (あなた) | YYYY-MM-DD | レビューメモ: ... |

4. 返信ワークフローの実践 — 既存コメントに応答するコメントを投稿:
   ```bash
   ncli comment create <ページID> "確認しました。セクション2の詳細追記を対応します。"
   ```

5. 一連のワークフローを整理:
   ```
   コメントワークフロー
   =======================
   1. ncli fetch でコンテンツ確認
   2. AIで要約生成
   3. ncli page create で要約保存
   4. ncli comment create でレビューコメント投稿
   5. ncli comment list でコメント確認
   6. ncli comment create で返信投稿
   ```

**期待される結果**: コメントの投稿・一覧表示・返信の一連のフローが実行できる。

## ⚠️ よくあるトラブルと解決方法

**AskQuestionの設定例:**
```json
{
  "title": "トラブル内容を選択",
  "questions": [{
    "id": "trouble",
    "prompt": "当てはまる内容を1つ選んでください",
    "options": [
      {"id": "trouble_1", "label": "コメントが投稿できない"},
      {"id": "trouble_2", "label": "要約が長すぎてページ作成に失敗する"},
      {"id": "trouble_3", "label": "コメント一覧が空になる"},
      {"id": "trouble_4", "label": "要約の精度が低い"}
    ]
  }]
}
```

### トラブル1: コメントが投稿できない
**原因**: ページIDが間違っている、またはコメント権限がない
**解決方法**:
```text
以下を確認してください：
1. ページIDが正しいか（ncli fetch でページにアクセスできるか確認）
2. コメント内容が空でないか
3. ワークスペースの権限でコメントが許可されているか
```

### トラブル2: 要約が長すぎてページ作成に失敗する
**原因**: --body の内容がシェルの引数制限を超えている
**解決方法**:
```text
以下を試してください：
1. パイプ入力を使う: echo "<要約>" | ncli page create --body -
2. 要約をファイルに保存してから: cat summary.md | ncli page create --body -
3. 要約を短縮版にする
```

### トラブル3: コメント一覧が空になる
**原因**: コメントがページではなくブロックに紐づいている場合がある
**解決方法**:
```text
以下を確認してください：
1. 正しいページIDを指定しているか
2. Notionブラウザでコメントが表示されるか確認
3. ncli comment list <ページURL> でURLを直接指定して試す
```

### トラブル4: 要約の精度が低い
**原因**: 取得したコンテンツが不完全、または構造が複雑すぎる
**解決方法**:
```text
以下を試してください：
1. ncli fetch --json で詳細なデータを取得し直す
2. 要約対象を特定のセクションに絞る
3. AIに追加のコンテキスト（ページの目的、対象読者など）を提供する
```
