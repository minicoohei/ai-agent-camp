# 🎓 Lesson 14-6: ファクトチェック - 事実検証エージェント

## 📍 このセッションでやること

**Lesson 14-6: ファクトチェック - 事実検証エージェント** へようこそ！

| 項目 | 内容 |
|------|------|
| ゴール | ファクトチェックエージェントで記事内の事実主張を検証し、出典を付与する |
| 所要時間 | 約30分 |
| 使うスキル | fact-checker |
| 前提条件 | Gemini APIキー設定済み、Lesson 14-5（校閲済みドラフト）完了済み |
| 教材ページ | [Module 14: 記事作成](https://ai-agent.camp/ja/course/module-14) を並行参照 |

1. ファクトチェックの対象カテゴリを理解する
2. fact-checkerで事実検証を実行する

セッション終了時には、事実検証済み・出典付きの記事が完成しています。

**選択後の案内（例）**:
入力内容:

## ⚠️ よくあるトラブルと解決方法

Codex では通常チャットで選択肢を提示しながらでトラブル内容を選んでもらい、押すだけで案内します。

**AskQuestionの設定例:**
```json
{
  "title": "トラブル内容を選択",
  "questions": [{
    "id": "trouble",
    "prompt": "当てはまる内容を1つ選んでください",
    "options": [
      {"id": "trouble_1", "label": "ほとんどの主張が「要確認」になる"},
      {"id": "trouble_2", "label": "出典URLが見つからない"},
      {"id": "trouble_3", "label": "ファクトチェックが厳しすぎる"},
      {"id": "trouble_4", "label": "検証結果ファイルが生成されない"}
    ]
  }]
}
```


### トラブル1: 「ほとんどの主張が「要確認」になる」
**原因**: 記事内に出典のない主張が多い
**解決プロンプト**:
```text
以下の対処法を検討してください：
1. 一般的な事実（広く知られている情報）は「要確認」を「確認済み」に変更
2. 具体的なデータがない主張は「〜と考えられている」等の慎重な表現に変更
3. 重要な主張には公的な出典（官公庁、学術論文、公式サイト）を追加
```

### トラブル2: 「出典URLが見つからない」
**原因**: ニッチな情報、または一次情報が未公開
**解決プロンプト**:
```text
出典が見つからない場合の対処法：
1. 表現を「筆者の経験では」「一般的に」等に変更する
2. 類似の情報源（業界レポート、ニュース記事）を代替出典として使う
3. 主張自体を削除する（根拠がない主張は読者の信頼を損なう）
```

### トラブル3: 「ファクトチェックが厳しすぎる」
**原因**: ブログ記事に学術論文レベルの検証を適用している
**解決プロンプト**:
```text
記事の種類に応じて検証レベルを調整してください：
- ブログ記事: 数値と固有名詞の正確性を重視
- 解説記事: 因果関係と出典の正確性を重視
- 技術記事: コマンド、バージョン情報、手順の正確性を重視
意見やアドバイスは検証対象外です。
```

### トラブル4: 「検証結果ファイルが生成されない」
**原因**: 入力ファイルが見つからない
**解決プロンプト**:
```bash
入力ファイルのパスを確認してください：
ls output/article-14-5-proofread.md
ファイルが存在しない場合は、Lesson 14-5（/start-14-5）を先に完了してください。
```
