# Cursorの使い方 研修: 議事録を作成・レビューする

## このコマンドでやること

**@** または **ドラッグ＆ドロップ** で会議メモをAIに渡し、議事録にまとめたり表現をレビューしたりします。

| 項目 | 内容 |
|------|------|
| ゴール | meeting_memo.txt を渡して議事録形式の文書と（任意で）レビューを得る |
| 所要時間 | 約10〜15分 |
| 研修用ファイル | `course/foundation/cursor-workshop/meeting_memo.txt` |
| 教材ページ | [Cursorの使い方](../../../course/index.html) |

---

## Step 1: ファイルの場所を確認する

1. ワークスペース内の **`course/foundation/cursor-workshop/meeting_memo.txt`** を開いて内容を確認する。
2. 会議メモ・書き起こし風のテキストであることを把握する。

**確認**: このファイルを次のステップでチャットに渡します（@ で指定するか、ドラッグ＆ドロップ）。

---

## Step 2: ファイルをチャットに渡す（@ またはドラッグ＆ドロップ）

**方法A: @ で指定する**

1. Cursorのチャット入力欄で **@** を入力する。
2. 一覧から「File」を選び、**meeting_memo.txt**（`course/foundation/cursor-workshop/meeting_memo.txt`）を選択する。
3. ファイルがコンテキストに追加された状態になる。

**方法B: ドラッグ＆ドロップ**

1. エクスプローラーまたは Finder で **meeting_memo.txt** を開く。
2. ファイルをチャット入力欄に **ドラッグ＆ドロップ** する。
3. ファイルがチャットに追加された状態になる。

---

## Step 3: 指示を送って議事録を作成・レビューする

**Step 3-1: 議事録にまとめる**

次の指示を入力して送信する。

**指示例:**

```
このメモを議事録形式にまとめてください。日付・出席者・議題・決定事項・次回の順で書いてください。
```

**期待される結果**: 体裁の整った議事録が返る。

**Step 3-2: 表現をレビューする（任意）**

同じチャットで、続けて次のように依頼する。

**指示例:**

```
この議事録の表現をレビューして、改善案を出してください。
```

**期待される結果**: 表現の改善提案や修正例が返る。
