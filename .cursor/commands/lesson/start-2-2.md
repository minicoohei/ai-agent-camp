## ⚠️ よくあるトラブルと解決方法

AskUserQuestion（AskQuestion）でトラブル内容を選んでもらい、押すだけで案内します。

**AskQuestionの設定例:**
```json
{
  "title": "トラブル内容を選択",
  "questions": [{
    "id": "trouble",
    "prompt": "当てはまる内容を1つ選んでください",
    "options": [
      {"id": "trouble_1", "label": "数字が多すぎて見づらい"},
      {"id": "trouble_2", "label": "比較が分かりにくい"},
      {"id": "trouble_3", "label": "デザインが単調"},
      {"id": "trouble_4", "label": "ストーリーが伝わらない"}
    ]
  }]
}
```


### トラブル1: 「数字が多すぎて見づらい」
**原因**: 情報を詰め込みすぎている
**解決プロンプト**:
```
最も重要な3つの指標に絞ってください。
残りの情報は別のインフォグラフィックにするか、補足テキストとして追加してください。
```

### トラブル2: 「比較が分かりにくい」
**原因**: 数値の表現方法が統一されていない
**解決プロンプト**:
```
すべての数値をパーセンテージまたは倍率で表現してください：
- 「8時間→30分」ではなく「94%削減」
- 「100件→500件」ではなく「5倍増加」
```

### トラブル3: 「デザインが単調」
**原因**: 視覚的な要素が不足している
**解決プロンプト**:
```
以下の要素を追加してください：
- 各指標にアイコンを追加
- 重要な数字は大きなフォントで強調
- 色分けで項目を区別
- グラフやチャートを使用
```

### トラブル4: 「ストーリーが伝わらない」
**原因**: 情報の流れや関連性が不明確
**解決プロンプト**:
```
インフォグラフィックに以下の要素を追加してください：
- 明確なタイトル（結論を示す）
- 情報の流れを示す矢印
- 関連する指標をグループ化
- 最も伝えたいメッセージを最も目立たせる
```
