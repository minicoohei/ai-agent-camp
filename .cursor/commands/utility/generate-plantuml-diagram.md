# Generate PlantUML Diagram with Nano Banana Pro

このコマンドは、`tools/generate_plantuml_diagram.py` を使用して、PlantUMLファイルからVisio Flowchartテンプレート風のモダンなフローチャート画像を生成します。

## デザイン仕様

### レイアウト

- 全体のフローは縦方向（トップダウン）で統一
- PlantUML内で定義された「participant」ごとに、縦のスイムレーンを1つずつ配置
- スイムレーンの枠線は薄いグレー（#CCCCCC）、背景は白
- 各ステップは、対応する participant のスイムレーン内に必ず配置

### 図形スタイル

| 図形タイプ | スタイル |
|-----------|---------|
| 一般プロセス | 角丸長方形（白、枠線 #4A90E2、軽い影） |
| 内部処理（自己呼び出し） | 淡いブルー (#E8F1FF) の角丸長方形 |
| 受信/入力（他participantから） | 淡いグリーン (#E9F7EC) の角丸長方形 |
| 条件分岐（alt/else/opt） | 菱形（枠線 #7B61FF） |

### 矢印（フローライン）

- すべて直線または90度折れ線で統一、色はダークグレー（#555555）
- 矢印ヘッドは明確で視認性の高いスタイル
- 条件分岐は菱形の下から左右に分岐、alt/else ラベルを付与

### アイコン

- 図形左上に、処理の性質を示すフラットアイコンを小さく配置
- アイコンの線幅は 1.5〜2px、統一感を持たせる
- participant名や処理内容に応じて自動的に適切なアイコンを割り当て

### カラーパレット

| 要素 | カラー |
|------|--------|
| 背景 | 淡いグレー (#F7F7F7) |
| 一般プロセス | 白 |
| 内部処理 | 淡いブルー (#E8F1FF) |
| 受信/入力 | 淡いグリーン (#E9F7EC) |
| 分岐ラベル | 濃いグレー (#444444) |

### フォント

- サンセリフ体（Segoe UI, Helvetica, Noto Sans など）
- 図形内テキスト：18px前後
- ラベル（alt, else, opt）：14px

### スペーシング

- 図形間の垂直距離は 40〜60px に統一
- スイムレーンは均等な幅で揃える
- 全体のマージンを確保し、図形の水平位置は揃えて整然と配置

### 全体の雰囲気

- モダンでシンプルな UI 風デザイン
- 装飾を少なめに抑え、視認性重視
- 影はごく軽く、過度な立体表現は避ける
- 全体形状のバランスと整列を明確に保つ

## 実行手順

1. **パラメータの抽出**:
   ユーザーの入力から以下の情報を抽出してください。
   - **PlantUMLファイルパス**: 変換対象のPlantUMLファイル（必須）
   - **アスペクト比**: `auto` (default), `16:9`, `1:1`, `4:3`, `3:4`, `9:16`
   - **出力パス**: 省略時は `docs/diagrams/{ファイル名}_{timestamp}.png`

2. **ツールの実行**:
   以下の形式でコマンドを実行してください。
   ```bash
   uv run python tools/generate_plantuml_diagram.py "{PlantUMLファイルパス}" --aspect_ratio "{アスペクト比}" --output "{出力パス}"
   ```

3. **結果の確認**:
   - 生成された図解画像のパスを確認し、ユーザーに報告してください。
   - エラーが発生した場合は、エラーメッセージを表示してください。

## パラメータ一覧

| パラメータ | 必須 | デフォルト | 説明 |
|-----------|------|-----------|------|
| `plantuml_path` | ○ | - | PlantUMLファイルのパス（.puml） |
| `--output`, `-o` | - | 自動生成 | 出力画像パス |
| `--aspect_ratio`, `-a` | - | `auto` | アスペクト比（autoの場合はPlantUML構造から自動判定） |

## アスペクト比の自動判定

`auto` を指定した場合、以下のルールで自動判定されます：

| 条件 | アスペクト比 |
|------|-------------|
| participant数が5以上 | `21:9`（横長） |
| participant数が3-4 | `16:9` |
| シーケンスが長い（20ステップ以上） | `9:16`（縦長） |
| その他 | `16:9` |

## 使用例

### 基本的な使用（自動アスペクト比）
```
/generate-plantuml-diagram work/06.Porimu/sequence.puml
```

### アスペクト比を指定
```
/generate-plantuml-diagram work/project/flow.puml --aspect_ratio 16:9
```

### 出力先を指定
```
/generate-plantuml-diagram sequence.puml --output docs/diagrams/my_flow.png
```

### 複数オプションを組み合わせ
```
/generate-plantuml-diagram work/api_flow.puml --aspect_ratio 9:16 --output docs/api_sequence.png
```

## 処理フロー

1. **PlantUML読み込み**
   - ファイルからPlantUMLコードを読み込み
   - participant、メッセージ、分岐などの構造を解析

2. **プロンプト生成** (Gemini 2.5 Flash)
   - PlantUML構造を解析し、デザイン仕様を反映したプロンプトを作成
   - スイムレーン、図形タイプ、色分けを指定

3. **図解生成** (Nano Banana Pro)
   - 最適化されたプロンプトを使用してフローチャート画像を生成
   - Visio風のモダンでプロフェッショナルな図解を出力

## 注意事項

- 実行には `GEMINI_API_KEY` または `GOOGLE_API_KEY` が環境変数（または `.env`）に設定されている必要があります。
- 生成される図解は1枚の画像ファイル（PNG形式）です。
- 複雑なPlantUML（participant数が多い、ステップ数が多い）の場合、生成に時間がかかる場合があります。
- 日本語のラベルに対応しています。生成される図解内のテキストも日本語で表示されます。
