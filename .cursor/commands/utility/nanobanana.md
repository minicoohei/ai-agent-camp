# Nano Banana Pro 画像生成・編集

このコマンドは、`tools/nanobanana.py` を使用して、Nano Banana Pro（Gemini 3 Pro Image）で画像を生成・編集します。

## 機能

1. **テキストから画像生成（text-to-image）**: プロンプトのみで新しい画像を生成
2. **画像編集**: 既存の画像＋指示で画像を編集

## 実行手順

1. **パラメータの抽出**:
   ユーザーの入力から以下の情報を抽出してください。
   - **プロンプト**: 生成/編集の指示（必須）例: 「富士山の風景画」「背景をぼかす」
   - **入力画像パス**: 編集する場合のみ（任意）
   - **アスペクト比**: 生成時のみ有効。`1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `21:9`（デフォルト: `16:9`）
   - **セッション名**: 現在のチャットタイトル/プロジェクト名から推測（必須）
   - **出力パス**: 省略時は自動生成（`--session`指定時は`docs/generated/日付_セッション名/`フォルダに保存）

2. **ツールの実行**:

   **テキストから画像生成:**
   ```bash
   uv run python tools/nanobanana.py "{プロンプト}" --session "{セッション名}" --aspect-ratio "{アスペクト比}"
   ```

   **画像編集:**
   ```bash
   uv run python tools/nanobanana.py "{プロンプト}" --input "{入力画像パス}" --session "{セッション名}"
   ```

## セッション名について

`--session`引数には、現在のチャットのタイトルやコンテキストから適切な名前を推測して指定してください。
- 例: チャットタイトルが「Cursor Bootcamp バナー作成」→ `--session "cursor_bootcamp_banner"`
- 例: 「富士山の風景画を作って」というリクエスト → `--session "富士山風景画"`

これにより、画像は `docs/generated/20251223_cursor_bootcamp_banner/` のようにセッションごとのフォルダに整理されます。
