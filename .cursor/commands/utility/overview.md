# Overview - プロジェクト構造可視化

このコマンドは、`tools/project_overview.py` を使用して、serena MCPを活用してプロジェクト構造を可視化し、不足している機能や未実装部分を抽出します。

## 機能

- serena MCPでコードベースをシンボリックに探索
- プロジェクト構造をPlantUML形式で可視化（SVG画像として表示）
- **ファイル一覧と関数/クラス一覧を表示**
- 不足している機能や未実装部分を抽出
- HTML形式でレポート出力
- **情報が不足している場合は聞き直す**

## 設計方針

- **serena MCP活用**: シンボリックな探索で正確な構造把握
- **可視化重視**: PlantUML公式サーバー経由でSVG画像として構造図を表示
- **ファイル/関数一覧**: 各ファイルの説明と主要な関数を一覧表示
- **不足機能の特定**: 実装されている機能と不足している機能を明確化

## 実行手順

1. **パラメータの抽出**:
   ユーザーの入力から以下の情報を抽出してください。
   - **対象ディレクトリ**: 分析したいディレクトリ（オプション、デフォルト: プロジェクトルート）
   - **出力形式**: plantuml / wbs / all（オプション、デフォルト: all）
   - **出力パス**: 省略時は `docs/bootcamp/overview/overview_{timestamp}.html`

2. **情報不足時の対応**:
   必要な情報が不足している場合は、以下のように質問してください：
   ```
   プロジェクト概要を生成するために、以下を教えてください：
   
   1. 分析したいディレクトリはどこですか？（例: src/, scripts/）
   2. 出力形式の希望はありますか？（plantuml / wbs / all）
   ```

3. **ツールの実行**:
   以下の形式でコマンドを実行してください。
   ```bash
   uv run python tools/project_overview.py --directory "{対象ディレクトリ}" --format "{出力形式}" --output "{出力パス}"
   ```

4. **結果の確認**:
   - 生成されたHTMLファイルのパスを確認し、ユーザーに報告してください。
   - Live Serverで開く方法を案内してください。
   - エラーが発生した場合は、エラーメッセージを表示してください。

## 使用例

### 基本的な使用（プロジェクト全体を分析）
```
/overview
```

### 特定のディレクトリを分析
```
/overview --directory src/
```

### 出力形式を指定（WBSマインドマップのみ）
```
/overview --format wbs
```

### 複数オプションを組み合わせ
```
/overview --directory scripts/ --format plantuml --output docs/bootcamp/overview/scripts_overview.html
```

## 処理フロー

1. **serena MCPでコードベース探索**: シンボリックにプロジェクト構造を分析
2. **Gemini APIで解析**: ファイル一覧、関数一覧、説明を抽出
3. **構造の可視化**: PlantUMLでコンポーネント図とマインドマップを生成
4. **HTMLレポート生成**: わかりやすい形式でレポートを出力

## 出力内容

- **ファイル一覧と関数**: 各ファイルのパス、説明、主要な関数/クラス
- **プロジェクト構造図**: PlantUML形式のコンポーネント図（SVG画像）
- **マインドマップ（WBS）**: PlantUML形式の階層図（SVG画像）
- **モジュール一覧**: 各モジュールの役割と関係性
- **実装済み機能**: 現在実装されている機能のリスト
- **不足機能**: 未実装または不足している機能のリスト
- **推奨事項**: プロジェクト改善のための推奨事項

## serena MCPについて

serena MCPは、コードベースをシンボリックに探索することができるMCP（Model Context Protocol）です。

- プロジェクトの構造を明確に把握
- どのファイルで何をしているかを理解
- どの機能まで完了しているかを確認

## 注意事項

- serena MCPが利用可能な環境で実行してください
- 大きなプロジェクトの場合は、分析に時間がかかる場合があります
- PlantUML公式サーバー（plantuml.com）への接続が必要です
