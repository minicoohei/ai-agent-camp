# Generate Lecture Slide with Nano Banana Pro

このコマンドは、`tools/generate_slide.py` を使用して、プロフェッショナル講義用のスライドを生成します。
トピックを入力するだけで、必要な説明を自動取得し、統一されたデザインのスライドを作成します。

## デザイン仕様

すべてのスライドは以下の統一されたデザインで生成されます：

| 項目 | 仕様 |
|------|------|
| 背景 | 白 |
| メインカラー | 青 (#2563EB) |
| サブカラー | 黄色 (#FBBF24) |
| スタイル | フラットデザイン |
| 文字サイズ | 14pt以上 |
| テキスト量 | 少なめ（整頓されたイメージ） |
| アスペクト比 | 16:9 |

## 実行手順

1. **パラメータの抽出**:
   ユーザーの入力から以下の情報を抽出してください。
   - **トピック**: スライドのテーマ（必須）例: 「AI AgentのToolsの仕組み」
   - **スタイル**: `auto` (default), `title`, `content`, `diagram`, `summary`
   - **出力パス**: 省略時は `docs/slides/{トピック名}_{timestamp}.png`

2. **ツールの実行**:
   以下の形式でコマンドを実行してください。
   ```bash
   uv run python tools/generate_slide.py "{トピック}" --style "{スタイル}" --output "{出力パス}"
   ```

3. **結果の確認**:
   - 生成されたスライド画像のパスを確認し、ユーザーに報告してください。
   - エラーが発生した場合は、エラーメッセージを表示してください。

## スライドスタイル一覧

| スタイル | 説明 |
|----------|------|
| `auto` | AIが内容に応じて最適なレイアウトを自動選択（デフォルト） |
| `title` | タイトルスライド（大きなタイトル + サブタイトル） |
| `content` | コンテンツスライド（箇条書き・説明文） |
| `diagram` | 図解スライド（概念図・フローチャート風） |
| `summary` | まとめスライド（要点の整理） |

## 使用例

### 基本的な使用（自動スタイル）
```
/generate-slide AI AgentのToolsの仕組み
```

### タイトルスライドを生成
```
/generate-slide 機械学習入門セミナー --style title
```

### 図解スライドを生成
```
/generate-slide APIリクエストの流れ --style diagram
```

### コンテンツスライドを生成
```
/generate-slide データベースの正規化 --style content
```

### まとめスライドを生成
```
/generate-slide 今日の学習ポイント --style summary
```

### 出力先を指定
```
/generate-slide クラウドアーキテクチャ --output docs/slides/cloud_arch.png
```

### 複数オプションを組み合わせ
```
/generate-slide REST APIの設計原則 --style diagram --output docs/training/api_design.png
```

## 処理フロー

1. **コンテンツ生成** (Gemini 2.5 Flash)
   - トピックから講義に必要な説明・ポイントを自動取得
   - スライドに適した簡潔な文章に整理

2. **プロンプト最適化** (Gemini 2.5 Flash)
   - デザイン仕様を反映したスライド生成プロンプトを作成
   - スタイルに応じたレイアウト指示を生成

3. **スライド生成** (Nano Banana Pro)
   - 最適化されたプロンプトを使用してスライド画像を生成
   - 16:9 のプロフェッショナルな講義スライドを出力

## 注意事項

- 実行には `GEMINI_API_KEY`（推奨）が環境変数（または `.env`）に設定されている必要があります。
- 生成されるスライドは1枚の画像ファイル（PNG形式）です。
- 複数枚のスライドが必要な場合は、コマンドを複数回実行してください。
- 日本語のトピックに対応しています。生成されるスライド内のテキストも日本語になります。
