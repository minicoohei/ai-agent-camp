# TikTok動画 最適仕様リファレンス

## 基本スペック
| 項目 | 値 |
|------|-----|
| アスペクト比 | 9:16 |
| 解像度 | 1080×1920 |
| フレームレート | 30fps（推奨）/ 60fps |
| 最大長 | 10分（推奨: 15-60秒） |
| ファイル形式 | MP4 (H.264) |
| 最大ファイルサイズ | 287.6MB |
| ビットレート | 5-8 Mbps |

## セーフゾーン
```
上端から15%: ユーザー名、フォローボタン、音楽情報
下端から20%: いいね、コメント、シェア、レコード
右端から10%: いいね等のアイコン列
左端から5%: ユーザー名テキスト
```

実効コンテンツエリア: 左5% 〜 右90%, 上15% 〜 下80%

## キャプション/テキスト最適化

### フォント
- **推奨**: 太字ゴシック体（日本語: Noto Sans JP Bold, ヒラギノ角ゴ）
- **サイズ**: 54-76px（画面幅の5-7%）
- **避ける**: 細い書体、セリフ体（可読性低下）

### 色とコントラスト
- **白文字 + 黒ストローク(3px)**: どんな背景でも読める
- **代替**: 黒文字 + 白ストローク（明るい背景用）
- **アクセント**: ブランドカラーでキーワードだけ色変え

### テキスト量
- **1行**: 日本語5-8文字 / 英語2-3語
- **最大**: 2行まで
- **表示時間**: 1.5-3秒
- **切り替え**: 0.1秒のフェードまたはポップ

### アニメーション
| タイプ | 効果 | 用途 |
|--------|------|------|
| pop | scale 0.8→1.0 (150ms) | 標準、インパクト |
| fade | opacity 0→1 (200ms) | 控えめ、ナレーション字幕 |
| typewriter | 1文字ずつ表示 | 教育系、説明 |
| slide-up | Y+20px→0 (200ms) | リスト形式 |
| bounce | scale overshoot 1.1→1.0 | エンタメ、強調 |

## 動画構成のベストプラクティス

### フック（0-3秒）
- 最初の1秒で視聴者を掴む
- テキストは大きく、シンプルに
- 「？」で終わる質問形式が効果的

### 本題（3-25秒）
- 1カット2-4秒
- カット切り替えで飽きさせない
- キャプションはナレーションと同期

### CTA（最後2-3秒）
- 「フォロー」「プロフチェック」等の具体的アクション
- テキスト+指差しアニメ等で視線誘導
