# SNS投稿フォーマット集

## X (Twitter)

### 単発投稿
```
[フック（問題提起 or 驚き）]

[本文（価値提供 or 解決策）]

[CTA or 締め]

#ハッシュタグ1 #ハッシュタグ2
```

### スレッド形式（3-7ツイート）
```
🧵 1/ [強いフック — 読み続ける理由を作る]

2/ [背景・問題の深掘り]

3/ [解決策・知見1]

4/ [解決策・知見2]

5/ [具体例・データ]

6/ [まとめ・結論]

7/ [CTA — フォロー、RT、リンク]
```

### パターン別テンプレ

**How-to型**: 〇〇する方法を3ステップで解説👇
**リスト型**: 〇〇で成果を出すためにやった5つのこと
**逆説型**: 〇〇はやめた方がいい。理由↓
**データ型**: 〇〇を分析した結果、衝撃の事実が判明
**ストーリー型**: 3ヶ月前、〇〇だった。今は〇〇になった。やったことは…

## Instagram

### フィード投稿
```
[1行目: フック（125文字以内で勝負）]

[本文: 価値提供、ストーリー、教訓]

[CTA: 「保存してね」「コメントで教えて」等]

---
#ハッシュタグ × 20-30個
（大カテゴリ5 + 中カテゴリ10 + ニッチ10 + ブランド5）
```

### Reelsスクリプト
```
[0-3秒] フック（画面テキスト + 音声）
[3-15秒] 本題
[15-25秒] 展開
[25-30秒] CTA + 締め
```

### Stories
```
1枚目: 質問/投票（エンゲージメント獲得）
2枚目: 本題
3枚目: CTA（リンク or DM誘導）
```

## TikTok

### ショート動画スクリプト
```
[0-1秒] フック（「これ知ってた？」「〇〇がヤバい」）
[1-10秒] 本題（テンポよく）
[10-15秒] オチ or CTA
```

### トレンド活用
- トレンド音源 + オリジナルコンテンツ
- デュエット/ステッチで既存バズに乗る
- ハッシュタグチャレンジ参加

## YouTube

### ロング動画構成（10-15分）
```
[0:00-0:30] フック（結論先出し or 問題提起）
[0:30-1:00] イントロ（チャンネル紹介、概要）
[1:00-3:00] セクション1
[3:00-6:00] セクション2
[6:00-9:00] セクション3
[9:00-10:00] まとめ
[10:00-10:30] CTA（チャンネル登録、次の動画）
```
