## 各モジュールの概要

### Module 1: バナー生成
SNS投稿用バナー画像の作成。X、YouTube、Instagramなど各プラットフォーム向け。

### Module 2: 図表・フロー作成
業務フロー図、インフォグラフィック、PlantUMLダイアグラムの作成。

### Module 3: スクリーンショット分析
エラー診断、UI注釈、チュートリアル生成。Gemini Vision APIを活用。

### Module 4: データ分析
BigQuery接続、EDA（探索的データ分析）、可視化レポート生成。

### Module 5: PPTX操作
PowerPointファイルの解析、自動生成、テンプレート活用。

### Module 6: Slack検索
Slack APIを使ったメッセージ検索、タスク自動抽出。

### Module 7: 動画生成
キーフレーム抽出、絵コンテ作成、動画合成（Veo3/Fabric/FFmpeg）。

### Module 8: Google Apps Script
GASによるGoogle Workspace自動化、Clasp管理、トリガー設定。

### Module 9: GitHub Actions ✅
Gmail通知、Slack通知、CI/CD統合ワークフロー。

### Module 10: Notion連携
Notion APIによるデータベース操作、ページ作成、外部同期。

### Module 11: エージェント開発
カスタムCommand、Skill、MCP設定、ワークフロー設計。

## 使い方

### 1. 成果物の確認
各モジュールディレクトリのREADME.mdを読んで、期待される成果物を確認します。

### 2. レッスンの実行
対応するレッスンコマンドを実行します。

```bash
# 例: Module 1 レッスン1
/start-1-1
```

### 3. 成果物の比較
自分の成果物と`examples/final/`の正解例を比較します。

## 注意事項

- 成果物は「正解例」であり、唯一の正解ではありません
- 創造的なタスク（バナー、図表等）は多様な正解があります
- コードは参考実装として、自分なりの改善を推奨します
