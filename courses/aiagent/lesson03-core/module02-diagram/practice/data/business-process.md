# 営業プロセス

## フロー概要

BtoB SaaS 製品の営業プロセス（5ステップ）を以下に示します。

## ステップ詳細

### ステップ1: リード獲得
- **担当者**: マーケティングチーム / インサイドセールス
- **アクション**: ウェビナー・展示会・Web問い合わせからリードを獲得
- **成果物**: リード情報（会社名、担当者名、課題、規模）
- **ツール**: HubSpot / Salesforce にリード登録

### ステップ2: 初回提案
- **担当者**: インサイドセールス
- **アクション**: 電話/メールでコンタクト、製品概要を説明、初回ミーティングを設定
- **成果物**: 初回ミーティング日程確定
- **判定**: 見込み度合いを A/B/C でランク付け

### ステップ3: ヒアリング
- **担当者**: フィールドセールス
- **アクション**: 顧客の課題・要件を深掘り、現状のワークフローを把握
- **成果物**: ヒアリングシート（課題一覧、優先度、予算感、導入時期）
- **ポイント**: BANT 条件（Budget, Authority, Need, Timeline）を確認

### ステップ4: 見積・提案
- **担当者**: フィールドセールス / ソリューションアーキテクト
- **アクション**: カスタマイズ提案書作成、デモ実施、見積書提出
- **成果物**: 提案書、見積書、ROI 試算
- **ポイント**: 競合比較での優位性を明確に

### ステップ5: 受注 / 失注
- **担当者**: フィールドセールス / 営業マネージャー
- **受注の場合**: 契約締結 → カスタマーサクセスチームへ引き渡し
- **失注の場合**: 失注理由をCRMに記録 → ナーチャリングリストに追加
- **成果物**: 契約書（受注）/ 失注レポート（失注）
