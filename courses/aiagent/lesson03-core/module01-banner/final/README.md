# module01-banner 完成例

## 概要

SNS投稿用バナーを3プラットフォーム（X、Instagram、Facebook）向けに自動生成した完成例です。プラットフォームごとのサイズ・トーン・カラースキームの使い分けを実践しています。

## 成果物一覧

| ファイル | プラットフォーム | サイズ | 説明 |
|----------|----------------|--------|------|
| `output/x-post-banner.png` | X（旧Twitter） | 1200x675 | AI研修告知用バナー。professional トーン、cool カラースキーム |
| `output/instagram-feed.png` | Instagram フィード | 1080x1080 | AI活用訴求バナー。pop トーン、vivid カラースキーム |
| `output/facebook-ad.png` | Facebook 広告 | 1200x630 | ブートキャンプ広告バナー。urgent トーン、CTR重視 |

## 各バナーの設計意図

### X投稿用バナー
- **メッセージ**: 「AIエージェント研修 - Claude Code で業務効率化」
- **狙い**: タイムラインでの視認性を重視。プロフェッショナルなトーンでBtoB向けの信頼感を演出
- **カラー**: 寒色系（cool）で知的な印象

### Instagramフィード用バナー
- **メッセージ**: 「非エンジニアでもできるAI活用 - AIエージェント研修」
- **狙い**: 正方形フォーマットで視覚的インパクトを最大化。ポップなトーンで敷居の低さをアピール
- **カラー**: ビビッド（vivid）で目を引く配色

### Facebook広告用バナー
- **メッセージ**: 「業務効率3倍 - AIエージェント活用ブートキャンプ」
- **狙い**: 数値訴求で具体性を出し、CTAボタンでコンバージョンを促す。CTR最優先設計
- **CTA**: 「今すぐ申し込む」

## 使用ツール

- `banner-creator` スキル（`tools/banner_creator.py`）
- Gemini API（画像生成）

## 学習ポイント

1. プラットフォームごとにサイズとアスペクト比が異なることの理解
2. トーンとカラースキームの使い分けによる訴求力の違い
3. CTA（Call to Action）とメッセージ構成の重要性
4. --priority オプションによる最適化方針の指定
