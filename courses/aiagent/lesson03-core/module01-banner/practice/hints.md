# バナー生成のヒント

## 1. メッセージを明確に

バナーのメインメッセージは短く、具体的にしましょう。

```
# 悪い例（長すぎる）
--message "AIエージェントを活用して業務効率化を実現するための研修プログラムのご案内"

# 良い例（簡潔で具体的）
--message "業務効率3倍 - AI研修プログラム"
```

## 2. トーンを使い分ける

ターゲットやプラットフォームに合わせてトーンを選択します。

| トーン | 適したシーン | 例 |
|--------|-------------|-----|
| `professional` | BtoB、企業向け | 社内研修、コンサル |
| `pop` | BtoC、若年層向け | キャンペーン、SNS |
| `elegant` | 高級感 | ブランド、ファッション |
| `urgent` | 期間限定、セール | 割引、締切訴求 |
| `minimal` | シンプル志向 | テック企業、スタートアップ |
| `tech` | IT・テクノロジー | SaaS、AI関連 |

## 3. カラースキームの指定

プリセットカラーだけでなく、HEXコードで直接指定もできます。

```bash
# プリセットを使う場合
--color-scheme cool

# HEXコードで直接指定する場合
--color-scheme "#1a73e8"
```

ブランドカラーがある場合は HEX 指定が統一感を保てます。

## 4. サブコピーとCTAの活用

メインメッセージだけでなく、サブコピーとCTAを組み合わせると効果的です。

```bash
uv run python tools/banner_creator.py \
  --platform x_post \
  --message "業務効率3倍" \
  --sub-copy "非エンジニア向けAIエージェント研修" \
  --cta "無料体験はこちら" \
  --tone professional
```

**構成のポイント:**
- メインメッセージ: 数値やインパクトのある一言
- サブコピー: 補足説明やターゲット明示
- CTA: 次のアクションを促す

## 5. 複数バリエーションの活用

`--variants` オプションで一度に複数パターンを生成し、最も効果的なものを選びましょう。

```bash
uv run python tools/banner_creator.py \
  --platform instagram_feed \
  --message "AI研修プログラム" \
  --variants 3 \
  --session "ab_test"
```

A/Bテスト用に複数パターンを生成するのが効果的です。
