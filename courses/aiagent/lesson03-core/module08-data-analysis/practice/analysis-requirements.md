# 分析要件

## 分析の目的

ECサイトの売上データを多角的に分析し、以下のビジネス判断に役立つインサイトを抽出する。

1. **売上トレンドの把握**: 季節変動やピーク月の特定
2. **商品戦略の最適化**: カテゴリ別の売上構成から注力すべき商品群を特定
3. **地域戦略**: 地域ごとの販売傾向から物流・マーケティング施策を検討
4. **顧客理解**: セグメント別の購買パターンから CRM 施策を立案
5. **在庫最適化**: ABC分析で重点管理すべき商品を特定

## 各課題の詳細

### 課題1: 月別売上推移
- 可視化: 折れ線グラフ（X軸: 月、Y軸: 売上金額）
- 追加分析: 前月比成長率の算出
- 期待される洞察: ピーク月の特定、季節性パターン

### 課題2: カテゴリ別売上構成
- 可視化: 円グラフ（売上比率）+ 棒グラフ（金額）
- 追加分析: カテゴリ別の平均単価と販売数量
- 期待される洞察: 主力カテゴリ、成長ポテンシャルのあるカテゴリ

### 課題3: 地域別分析
- 可視化: 横棒グラフ（地域別売上）+ ヒートマップ（地域×カテゴリ）
- 追加分析: 地域別の1注文あたり平均金額
- 期待される洞察: 高単価地域、地域ごとの嗜好の違い

### 課題4: 顧客セグメント分析
- 可視化: ボックスプロット（ランク別購入金額）+ 棒グラフ（ランク別購入頻度）
- 追加分析: ランク別のリピート率、ランクアップ候補の特定
- 期待される洞察: 高LTV顧客の特徴、ランク別の行動差

### 課題5: 商品ABC分析
- 可視化: パレート図（棒グラフ+累積線グラフ）
- 追加分析: 各ランクの商品数と売上比率
- 期待される洞察: 重点管理すべき商品、カットすべき低回転商品
