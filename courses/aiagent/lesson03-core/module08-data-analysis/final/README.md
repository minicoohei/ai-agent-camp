# module08-data-analysis 完成例

## 概要

ECサイトの売上データ（500件）に対し、月別推移・カテゴリ別・地域別の可視化とABC分析を実施し、ビジネスインサイトを導出した完成例です。

## 成果物一覧

### グラフ（output/charts/）

| ファイル | 種類 | 内容 |
|----------|------|------|
| `monthly-sales.png` | 折れ線グラフ | 2025年 月別売上推移 |
| `category-sales.png` | 棒グラフ + 円グラフ | カテゴリ別売上金額と比率 |
| `region-sales.png` | 横棒グラフ | 地域別売上金額 |
| `rank-boxplot.png` | ボックスプロット | 会員ランク別購入金額分布 |
| `abc-pareto.png` | パレート図 | 商品ABC分析（棒+累積線） |

### 分析レポート（output/）

| ファイル | 内容 |
|----------|------|
| `insights.md` | 5課題に対するインサイトとビジネス提案 |

## 分析サマリー

- **総売上**: 7,221,700円（500件）
- **最大カテゴリ**: ファッション（19.6%）
- **最大地域**: 大阪（1,084,500円）
- **ABC分析**: A=21商品, B=17商品, C=12商品

## 使用ツール

- Python（pandas, matplotlib, seaborn）
- practice/data/ のCSV/JSONデータセット

## 学習ポイント

1. pandas による CSV データの読み込みと集計
2. matplotlib / seaborn による多様なグラフ作成
3. ABC分析（パレート分析）の手法
4. データからビジネスインサイトを導出する思考法
