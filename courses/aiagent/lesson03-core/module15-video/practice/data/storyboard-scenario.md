# シナリオ: AIエージェント研修プロモーション動画

## 動画概要
- **尺**: 30秒
- **形式**: 縦型（9:16）
- **目的**: AIエージェント研修の魅力を伝え、参加者を募集する
- **トーン**: プロフェッショナルだが親しみやすい

## シーン構成（5シーン）

### シーン 1: 問題提起（0:00-0:06）
オフィスで大量のスプレッドシートや書類に囲まれ、疲れた表情で作業するビジネスパーソン。画面には「毎日の繰り返し作業、もう限界...」のテキスト。暗めの照明で停滞感を演出。

### シーン 2: 出会い（0:06-0:12）
同じビジネスパーソンがノートPCで Claude Code の画面を発見する瞬間。画面が明るく光り、表情が興味津々に変わる。テキスト「AIエージェントという選択肢」。

### シーン 3: 実践中（0:12-0:18）
研修の様子。参加者がPCに向かい、Claude Code を操作している。画面にはコードやバナー画像が生成されている様子。活気ある雰囲気。テキスト「プロンプト1つで、ここまでできる」。

### シーン 4: 成果発表（0:18-0:24）
チームで成果を見せ合っている場面。自動生成されたレポートやスライドが画面に映る。メンバーが笑顔で会話。テキスト「チーム全員がAI活用人材に」。

### シーン 5: CTA（0:24-0:30）
研修ロゴとキャッチコピーのクロージング画面。テキスト「CursorBootcamp - 次はあなたの番です」。申し込みURL表示。
