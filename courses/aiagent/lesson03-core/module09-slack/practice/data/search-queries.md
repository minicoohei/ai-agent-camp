# 検索クエリ例

以下の10個の検索クエリを使って `sample-conversations.json` を検索してください。

## クエリ一覧

| # | クエリ | 検索意図 |
|---|--------|---------|
| 1 | `デプロイ` | リリース・デプロイ関連のメッセージ |
| 2 | `田中` | 田中さんに関連するメッセージ |
| 3 | `バグ` | バグ報告・修正に関するメッセージ |
| 4 | `ミーティング` | 会議・打ち合わせの連絡 |
| 5 | `お願い` | 依頼・リクエストのメッセージ |
| 6 | `確認` | 確認依頼・承認関連 |
| 7 | `完了` | タスク完了報告 |
| 8 | `来週` | 来週の予定・計画に関するメッセージ |
| 9 | `API` | API関連の技術的な議論 |
| 10 | `レビュー` | コードレビュー・ドキュメントレビュー |

## 検索のポイント

- 単純なキーワード一致だけでなく、文脈を考慮した検索を試みる
- 同義語（例: 「ミーティング」と「MTG」と「打ち合わせ」）も検索対象にする
- 否定検索（特定ワードを除外）も試してみる
