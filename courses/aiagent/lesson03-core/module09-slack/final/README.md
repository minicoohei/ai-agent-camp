# module09-slack 完成例

## 概要

50件のSlack会話ログに対し、キーワード検索・タスク抽出・週次サマリー生成を行った完成例です。JSONデータの読み込みから分析・レポート作成までを一気通貫で実施しています。

## 成果物一覧

| ファイル | 種類 | 説明 |
|----------|------|------|
| `output/search-results.json` | JSON | 10クエリの検索結果（ヒット件数とメッセージ一覧） |
| `output/extracted-tasks.md` | Markdown | 20件のタスクリスト（担当者、内容、期限、ステータス） |
| `output/weekly-summary.md` | Markdown | 週次サマリーレポート（チャネル別活動、決定事項、アクションアイテム） |

## 分析結果サマリー

### 検索結果
- 10クエリで合計82件のヒット
- 最多: 「お願い」（20件） → 依頼メッセージが多い
- 技術系: 「API」（7件）、「デプロイ」（4件）

### タスク抽出
- 20件のタスクを抽出
- 完了: 10件（50%）、進行中: 3件（15%）、未着手: 7件（35%）
- 来週のアクションアイテム: 7件

### 週次サマリー
- 全10チャネルで50メッセージ
- 最活発: #dev-team（10件）、#project-alpha（8件）
- 主要決定: API設計FIX、キャンペーンバナー確定、テスト目標達成

## 使用ツール

- Python（json, re, collections）
- サンプルデータ: 50件の会話ログ

## 学習ポイント

1. JSONデータの読み込みとキーワード検索
2. 正規表現によるパターンマッチでのタスク抽出
3. チャネル別・日付別の集計と分析
4. ビジネス文脈を踏まえたサマリー作成
