# 日報生成エージェント 仕様書

## 目的
Git のコミットログを分析し、Markdown 形式の日報を自動生成するエージェント。

## 入力
- Git リポジトリ（カレントディレクトリ）
- 対象日付（デフォルト: 当日）
- 対象ブランチ（デフォルト: 現在のブランチ）

## 出力
- Markdown 形式の日報ファイル

## 出力フォーマット

```markdown
# 日報: YYYY-MM-DD

## 作業者
{Git の user.name}

## 本日の作業内容

### 機能追加
- [コミットメッセージ1] (ファイル数: N)
- [コミットメッセージ2] (ファイル数: N)

### バグ修正
- [コミットメッセージ3] (ファイル数: N)

### その他
- [コミットメッセージ4] (ファイル数: N)

## 統計
- コミット数: X
- 変更ファイル数: Y
- 追加行数: +Z / 削除行数: -W

## 明日の予定
（手動記入エリア）
```

## コミット分類ルール

| プレフィックス | カテゴリ |
|---------------|---------|
| `feat:`, `add:` | 機能追加 |
| `fix:`, `bugfix:` | バグ修正 |
| `refactor:` | リファクタリング |
| `docs:` | ドキュメント |
| `test:` | テスト |
| `chore:`, `ci:` | その他 |
| プレフィックスなし | その他 |

## 処理フロー

1. `git log --since="today 00:00" --format=...` で当日のコミットを取得
2. コミットメッセージのプレフィックスでカテゴリ分類
3. `git diff --stat` で統計情報を取得
4. Markdown テンプレートに埋め込んで出力
5. `output/reports/daily-report-YYYY-MM-DD.md` に保存
