# module03-screenshot 完成例

## 概要

SaaS型ビジネス分析ダッシュボードのスクリーンショットに対し、UI構成分析・ユーザビリティ評価・アクセシビリティ診断を行った完成例です。

## 成果物一覧

| ファイル | 種類 | 説明 |
|----------|------|------|
| `output/ui-analysis-report.md` | UI分析レポート | SaaS ダッシュボードの構成分析、ユーザビリティ評価、改善提案 |

## レポート内容

### UI分析レポート（ui-analysis-report.md）

SaaS型ビジネス分析ダッシュボードに対する包括的なUI分析レポートです。

**分析項目:**
1. **画面構成**: サイドバー、ヘッダー、メインコンテンツの3エリア構成を図解
2. **UI要素の洗い出し**: ナビゲーション、KPIカード、チャート、データテーブルの各要素を列挙
3. **ユーザビリティ評価**: 良い点4つと改善提案4つを重要度付きで記載
4. **アクセシビリティ**: WCAG 2.1 準拠の観点から4つの問題点と推奨対応を記載

## 学習ポイント

1. スクリーンショットから構造的に情報を読み取る方法
2. ユーザビリティ評価の観点（ナビゲーション、情報階層、フィードバック）
3. アクセシビリティ基準（WCAG 2.1）に基づいた評価
4. 改善提案の優先度付け（重要度: 高/中/低）

## 使用ツール

- `screenshot-analyzer` スキル（`tools/screenshot_analyzer.py`）
- `nanobanana` スキル（モックアップ画像生成）
