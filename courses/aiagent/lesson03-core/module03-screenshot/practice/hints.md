# スクリーンショット分析のヒント

## UI分析のチェックリスト

### レイアウト
- ヘッダー、サイドバー、メインコンテンツ、フッターの構成
- グリッドシステムの一貫性
- 余白（マージン/パディング）のバランス

### ナビゲーション
- メニュー構造は分かりやすいか
- 現在位置（パンくずリスト等）の表示
- 戻る/進むの操作性

### 視覚的階層
- 情報の優先度がデザインに反映されているか
- 見出し・本文・注釈のサイズ差
- 色によるグルーピング

### インタラクション
- ボタンのクリック可能性が明確か
- ホバー/フォーカス状態の存在
- フィードバック（成功/エラー表示）

## 注釈追加のコツ

1. **少ない方が良い**: 1画面に5箇所以内の注釈に抑える
2. **対比を使う**: 赤い枠は控えめなUIに対して目立つ
3. **番号で順序を示す**: 操作手順は数字で明確に
4. **余白に配置**: コールアウトはUI要素と重ねない

## チュートリアル作成のポイント

1. **1ステップ1アクション**: 各ステップは1つの操作だけ
2. **前後関係を明確に**: 「次に」「その後」で手順をつなぐ
3. **期待される結果を書く**: 操作後に何が起きるかを明記
4. **つまずきポイントを補足**: よくある間違いをNoteで追記
