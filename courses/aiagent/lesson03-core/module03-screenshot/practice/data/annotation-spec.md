# 注釈スタイル仕様

## 赤枠（ハイライトボックス）

- **色**: `#FF0000`（赤）
- **線幅**: 3px
- **角丸**: 4px
- **用途**: 重要なUI要素（ボタン、入力欄、メニュー等）を囲む

## 矢印

- **色**: `#FF0000`（赤）
- **線幅**: 2px
- **矢印サイズ**: 12px
- **スタイル**: 直線またはカーブ
- **用途**: 操作の流れ、クリック位置の指示

## コールアウト（吹き出し）

- **背景色**: `#FFF9C4`（薄黄色）
- **枠色**: `#F9A825`（オレンジ）
- **テキスト色**: `#212121`（ダークグレー）
- **フォントサイズ**: 14px
- **パディング**: 8px
- **用途**: 補足説明、操作手順の番号付き説明

## 番号マーカー

- **形状**: 円形
- **背景色**: `#1565C0`（ブルー）
- **テキスト色**: `#FFFFFF`（白）
- **サイズ**: 直径 28px
- **フォント**: ボールド
- **用途**: ステップ番号（1, 2, 3...）を示す

## 配置ルール

1. 注釈はUI要素と重ならないように配置
2. 矢印の方向は左→右、上→下を基本とする
3. コールアウトは対象要素の近くに配置し、リーダー線で接続
4. 番号マーカーは操作順序に従って配置
5. 注釈の密度が高くなりすぎないよう、1画面あたり最大5〜6箇所に抑える
