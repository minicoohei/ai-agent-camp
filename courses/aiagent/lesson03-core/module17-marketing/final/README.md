# module17-marketing 完成例

## 概要

架空SaaS「SmartTask Pro」のマーケティング施策を一気通貫で作成した完成例です。マーケティング企画書、SNS投稿コンテンツ、SEO監査レポート、LPコピーの4つの成果物カテゴリを含みます。

## 成果物一覧

| ファイル | 種類 | 説明 |
|----------|------|------|
| `output/marketing-plan.md` | 企画書 | SmartTask Pro マーケティング企画書（KPI・施策・スケジュール） |
| `output/x-post-drafts.md` | SNSコンテンツ | X投稿テキスト3パターン（ペルソナ別） |
| `output/x-post-banner.png` | 画像 | X投稿用バナー（1200x675px、professional トーン） |
| `output/seo-audit-report.md` | SEOレポート | テクニカル/オンページ/コンテンツの3観点SEO監査 |
| `output/keyword-strategy.md` | キーワード戦略 | メインKW5個+ロングテール15個+クラスター設計 |
| `output/lp-copy-v1.md` | LPコピー | ランディングページコピー原案（全セクション） |
| `output/lp-copy-v2a.md` | LPコピー | A/Bテスト案A「課題解決」アプローチ |
| `output/lp-copy-v2b.md` | LPコピー | A/Bテスト案B「成果訴求」アプローチ |

## 各成果物の解説

### マーケティング企画書（marketing-plan.md）
- 3ペルソナ×3チャネルのマトリックスで施策を整理
- KPI: X投稿インプレッション月間10万回、LP CVR 3%、MQL 月間50件
- 4週間のローンチスケジュール付き

### X投稿テキスト（x-post-drafts.md）
- パターンA: 営業マネージャー向け（業務効率化訴求）
- パターンB: マーケティング担当向け（時間節約訴求）
- パターンC: 経営者向け（ROI・実績訴求）

### SEO監査レポート（seo-audit-report.md）
- テクニカルSEO: Core Web Vitals、モバイル対応、構造化データ
- オンページSEO: メタタグ、見出し構造、内部リンク
- コンテンツSEO: E-E-A-T評価、更新頻度、競合比較

### キーワード戦略（keyword-strategy.md）
- ピラーページ: 「タスク管理ツール」を中心にクラスター構成
- メインKW5個+ロングテール15個を検索意図別に分類
- コンテンツカレンダーとの紐付け

### LPコピー & A/Bテスト
- v1: バランス型（全ペルソナ対応）
- v2a: 課題解決アプローチ（ペインポイント強調→解決策提示）
- v2b: 成果訴求アプローチ（数値実績→信頼性→CTA）

## 使用ツール

- `banner-creator` スキル（`tools/banner_creator.py`）— X投稿バナー生成
- `nanobanana` スキル（`tools/nanobanana.py`）— ヒーロー画像生成
- Claude Code — 企画書、コピーライティング、SEO分析

## 学習ポイント

1. ペルソナに基づいたメッセージ設計の重要性
2. SEO監査の3つの観点（テクニカル/オンページ/コンテンツ）
3. A/Bテストにおける変数の分離と仮説設定
4. ブランドガイドラインに準拠したコンテンツ制作
5. AIツールを活用したマーケティングワークフローの効率化
