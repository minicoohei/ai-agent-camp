# module17-marketing ヒント集

## タスク1: マーケティング企画 & X投稿

### 企画書のコツ
- **SMART な KPI 設定**: 「認知度向上」ではなく「X投稿のインプレッション月間10万回」のように具体的に
- **ペルソナ×チャネルのマトリックス**: どのペルソナにどのチャネルでリーチするかを表で整理すると分かりやすい

### X投稿のコツ
- **フック（冒頭3秒）**: タイムラインで目を止めてもらう一文が最重要
- **数値を入れる**: 「業務効率化」→「業務時間を40%削減」
- **CTA を明確に**: 「詳しくはプロフィールのリンクから」
- **ハッシュタグ**: 3〜5個が最適。人気タグ+ニッチタグを混ぜる

### バナー生成のパラメータ例
```bash
# プロフェッショナル寄り
--tone professional --color-scheme cool --priority ctr

# カジュアル寄り
--tone casual --color-scheme warm --priority engagement
```

## タスク2: SEO監査 & キーワード戦略

### SEO監査の観点
1. **テクニカルSEO**
   - Core Web Vitals（LCP, FID, CLS）の推定
   - モバイルフレンドリーか
   - robots.txt / sitemap.xml の有無
   - 構造化データ（JSON-LD）の実装

2. **オンページSEO**
   - タイトルタグ: 30〜60文字
   - メタディスクリプション: 120〜160文字
   - H1タグ: ページに1つ
   - 画像 alt テキスト

3. **コンテンツSEO**
   - E-E-A-T（経験・専門性・権威性・信頼性）
   - コンテンツの鮮度
   - 内部リンク構造

### キーワード選定のフレームワーク
- **検索意図の分類**: Informational / Navigational / Transactional / Commercial
- **トピッククラスター**: ピラーページ（広いテーマ）→ クラスターページ（具体的サブトピック）
- **SaaS 向けキーワード例**: 「タスク管理ツール 比較」「プロジェクト管理 無料」「チーム 業務効率化」

## タスク3: LPコピーライティング

### コピーライティングのフレームワーク
- **AIDA**: Attention → Interest → Desire → Action
- **PAS**: Problem → Agitate → Solution
- **4U**: Urgent, Unique, Ultra-specific, Useful

### A/Bテストの設計ポイント
- **1変数ずつテスト**: ヘッドライン or CTA or 画像を1つだけ変える
- **仮説を明文化**: 「課題訴求の方がCVRが高い」と予測を立ててからテスト
- **サンプルサイズ**: 統計的有意差を出すために十分なトラフィックが必要

### LPの構成テンプレート
1. ヒーローセクション: キャッチコピー + CTA
2. 課題提起: ペインポイントの列挙
3. 解決策: プロダクトの紹介
4. 機能紹介: 3つの主要機能
5. 社会的証明: 導入企業数、レビュー
6. 料金プラン
7. FAQ
8. 最終CTA

## タスク4: Pencil MCP

### Pencil MCP の基本操作
```
# ドキュメント作成
get_editor_state → open_document("new")

# フレーム挿入
batch_design: frame=I(document, {type: "frame", ...})

# テキスト挿入
batch_design: text=I(frame, {type: "text", content: "..."})

# 画像生成
batch_design: G("frameId", "ai", "プロンプト")
```

### バナーデザインのポイント
- **視覚的階層**: キャッチコピー > サブテキスト > CTA の順に目立たせる
- **コントラスト**: 背景色と文字色のコントラスト比 4.5:1 以上
- **余白**: 詰め込みすぎない。要素間に十分なパディング
