# module17-marketing 演習: マーケティング担当者の1週間

## 概要

架空の SaaS プロダクト「SmartTask Pro」のマーケティング施策を一気通貫で体験します。
企画立案→SNS投稿→SEO分析→LPコピーライティング→デザインモックアップまで、AIスキルを活用したマーケティングワークフローを実践します。

## 前提条件

- `banner-creator` スキルが実行可能であること
- `nanobanana` スキルが実行可能であること（Gemini API キー設定済み）
- `practice/data/` 内の参照データを事前に確認しておくこと

## タスク1: マーケティング企画 & X投稿コンテンツ作成

### ゴール
`data/product-info.json` の商品情報を基に、マーケティング企画書とX投稿コンテンツを作成する。

### 手順

1. `data/product-info.json` を読み込み、プロダクトの特徴・ターゲット・差別化ポイントを把握する
2. `data/target-persona.md` のペルソナ情報を参照し、各ペルソナに刺さるメッセージを考える
3. マーケティング企画書（`marketing-plan.md`）を作成する
   - 目的、ターゲット、KPI、施策概要、スケジュールを含めること
4. X投稿テキスト3パターン（`x-post-drafts.md`）を作成する
   - 各パターンで異なるペルソナをターゲットにすること
   - 140文字以内、ハッシュタグ付き
5. バナー画像を1枚生成する

```bash
uv run python tools/banner_creator.py --platform x_post \
  --message "SmartTask Pro - AIが変える、チームの働き方" \
  --tone professional --color-scheme cool
```

### 成果物
- `marketing-plan.md`
- `x-post-drafts.md`
- `x-post-banner.png`

## タスク2: SEO監査レポート & キーワード戦略

### ゴール
仮想サイト「smarttaskpro.example.com」のSEO課題を診断し、キーワード戦略を策定する。

### 手順

1. `data/competitor-analysis.md` で競合情報を確認する
2. 以下の観点でSEO監査レポート（`seo-audit-report.md`）を作成する
   - テクニカルSEO（ページ速度、モバイル対応、構造化データ）
   - オンページSEO（タイトルタグ、メタディスクリプション、見出し構造）
   - コンテンツSEO（品質、更新頻度、内部リンク）
   - 被リンク状況の推定
3. キーワード戦略（`keyword-strategy.md`）を作成する
   - メインキーワード 5個（検索ボリューム・競合度の推定付き）
   - ロングテールキーワード 15個
   - トピッククラスター設計（ピラーページ + クラスターページ構成）

### 成果物
- `seo-audit-report.md`
- `keyword-strategy.md`

---

## タスク3: LPコピーライティング & A/Bテスト案

### ゴール
SmartTask Pro のランディングページコピーを作成し、A/Bテスト用の2バリエーションを用意する。

### 手順

1. `data/target-persona.md` のペルソナ情報を再確認する
2. `data/brand-guidelines.md` のブランドガイドラインに準拠したLPコピー原案（`lp-copy-v1.md`）を作成する
   - ヒーローセクション（キャッチコピー + サブコピー）
   - 課題提起セクション
   - 機能紹介セクション（3つの主要機能）
   - 導入事例 / 数値実績
   - CTA（Call to Action）
3. A/Bテスト用バリエーションを2つ作成する
   - `lp-copy-v2a.md`: 「課題解決」アプローチ（ペインポイント強調）
   - `lp-copy-v2b.md`: 「成果訴求」アプローチ（数値・実績強調）

### 成果物
- `lp-copy-v1.md`
- `lp-copy-v2a.md`
- `lp-copy-v2b.md`

## タスク4: Pencil MCP でデザインモックアップ（応用）

### ゴール
Pencil MCP を使って、X投稿用の広告バナーデザインモックアップを作成する。

### 手順

1. `data/brand-guidelines.md` のカラーパレットとトーンを確認する
2. Pencil MCP の `open_document` で新規ドキュメントを作成する
3. 以下の要素を含む広告バナーモックアップを設計する
   - ブランドカラーを使用した背景
   - キャッチコピー + サブテキスト
   - CTA ボタン
   - プロダクトのスクリーンショット（プレースホルダー）

> **注意**: このタスクは応用課題です。Pencil MCP の基本操作に慣れてから取り組んでください。
