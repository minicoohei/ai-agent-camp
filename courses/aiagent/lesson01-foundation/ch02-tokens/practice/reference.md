# 参照テキスト: トークン

## トークンとは

LLM がテキストを処理する際の最小単位。文字でも単語でもなく、その中間的な単位です。英語では1トークンが約4文字、日本語では1文字が1〜3トークンに相当することが多いです。

## トークン化アルゴリズム

### BPE（Byte Pair Encoding）
- GPT シリーズで採用
- 頻出する文字ペアを反復的にマージして語彙を構築
- 例: "low" "lower" "lowest" → "low", "er", "est"

### SentencePiece
- Google が開発、Gemini/Llama で採用
- 言語に依存しないサブワード分割
- 空白も含めて統一的に処理

### WordPiece
- BERT で採用
- BPE に似ているが、尤度ベースでマージを決定

## トークン数の例

| テキスト | 英語トークン数 | 日本語トークン数 |
|----------|-------------|--------------|
| "Hello" | 1 | - |
| "Hello, world!" | 4 | - |
| "こんにちは" | - | 1〜3 |
| "人工知能は素晴らしい" | - | 5〜10 |
| 1ページ（約500文字） | 約125 | 約250〜500 |

## コスト計算方法

### 基本式
```
コスト = (入力トークン数 x 入力単価) + (出力トークン数 x 出力単価)
```

### 料金例（2025年時点の概算）

| モデル | 入力 (1Mトークン) | 出力 (1Mトークン) |
|--------|----------------|----------------|
| GPT-4o | $2.50 | $10.00 |
| Claude 3.5 Sonnet | $3.00 | $15.00 |
| Gemini 2.0 Flash | $0.075 | $0.30 |

### コスト最適化のコツ
- プロンプトを簡潔にする（入力トークン削減）
- `max_tokens` を必要最小限に設定
- キャッシュを活用（同じプロンプトの再利用）
- 用途に応じてモデルを使い分け（Flash で十分なら Flash を使う）

## トークン数の確認方法

### OpenAI tiktoken
```python
import tiktoken
enc = tiktoken.encoding_for_model("gpt-4o")
tokens = enc.encode("Hello, world!")
print(len(tokens))  # → 4
```

### Anthropic
```python
import anthropic
client = anthropic.Anthropic()
result = client.count_tokens("テキスト")
```

### 概算ルール
- 英語: 1トークン ≈ 4文字 ≈ 0.75語
- 日本語: 1文字 ≈ 1〜3トークン
- コード: 通常のテキストよりトークン効率が良い
