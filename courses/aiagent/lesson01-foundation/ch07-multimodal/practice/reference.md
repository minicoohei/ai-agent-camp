# 参照テキスト: マルチモーダル

## VLM（Vision-Language Model）とは

テキストと画像の両方を理解・生成できるAIモデル。テキストのみの LLM を拡張し、視覚情報を処理する能力を追加したものです。

## 3層構造

### 1. Vision Encoder（視覚エンコーダ）
- 画像をベクトル表現に変換
- 一般的に ViT（Vision Transformer）を使用
- 画像をパッチに分割し、各パッチをトークンとして処理

### 2. Projection Layer（射影層）
- 画像ベクトルをテキストベクトルの空間にマッピング
- Vision Encoder と Language Model の橋渡し
- 線形射影やアダプタモジュールで実装

### 3. Language Model（言語モデル）
- 統合されたベクトルからテキストを生成
- 通常の LLM アーキテクチャ（Transformer Decoder）
- 画像コンテキストを考慮した応答を生成

## 画像→テキスト→応答のパイプライン

```
画像入力
  ↓
パッチ分割（例: 14x14 のグリッド）
  ↓
Vision Encoder（各パッチをベクトル化）
  ↓
Projection（画像トークンに変換）
  ↓
テキストトークンと結合
  ↓
Language Model で推論
  ↓
テキスト応答を生成
```

## マルチモーダルの活用例

### 画像理解
- スクリーンショットの分析
- グラフ・チャートの読み取り
- UI デザインのレビュー
- OCR（文字認識）

### 画像生成
- テキストからのイラスト生成
- 既存画像の編集・加工
- バナー・ロゴのデザイン

### 動画処理
- キーフレーム抽出と分析
- 動画の内容要約
- 字幕の自動生成

## トークンコスト

画像はテキストよりもトークンを多く消費します:
- 低解像度画像: 約85トークン
- 高解像度画像: 約850〜1600トークン
- 画像サイズとトークン数は比例する傾向
