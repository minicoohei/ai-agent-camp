# 参照テキスト: AI コーディングツール操作

## 3つの入口

- **Cursor**: VS Code ベース。slash command とエディタ統合が強い
- **Claude Code**: ターミナル中心。repo guide と skill/hook の活用が強い
- **Codex**: `AGENTS.md`、skills、tools、repo hooks を軸に進める

## Cursor の AI モード

### Agent モード
- 最も自律的なモード
- ファイルの読み書き、ターミナルコマンド実行が可能
- 複数ステップのタスクを自動で実行
- 用途: 機能実装、バグ修正、リファクタリング

### Ask モード
- 質問応答に特化
- コードの説明、設計相談に使用
- ファイルを直接変更しない
- 用途: コード理解、技術相談

### Edit モード
- 選択したコード範囲を直接編集
- インラインで変更提案を表示
- 用途: 部分的なコード修正

### Manual モード
- AI 支援なし（通常のエディタ）
- 手動でコードを書きたい場合に使用

## ショートカットキー一覧

### AI 操作

| ショートカット | 機能 | 説明 |
|-------------|------|------|
| `Cmd+L` | AI チャットを開く | サイドパネルのチャット |
| `Cmd+I` | インライン編集 | 選択範囲の AI 編集 |
| `Cmd+K` | コマンドパレット（AI） | AI にコマンドを指示 |
| `Cmd+Shift+I` | Composer を開く | マルチファイル編集 |
| `Tab` | 補完の承認 | AI 補完を確定 |
| `Esc` | 補完のキャンセル | AI 補完を拒否 |

### 基本操作

| ショートカット | 機能 |
|-------------|------|
| `Cmd+Shift+P` | コマンドパレット |
| `Cmd+P` | ファイルを開く |
| `Cmd+B` | サイドバー切り替え |
| `Cmd+J` | ターミナル切り替え |
| `Cmd+Shift+E` | エクスプローラー |
| `Cmd+Shift+F` | 検索 |
| `Cmd+Shift+G` | Git |

## Claude Code / Codex の基本導線

### Claude Code
- `CLAUDE.md` を読む
- skill / hook / subagent を使って進める
- slash command や repo guide を入口にする

### Codex
- `AGENTS.md` を読む
- `aiagent-guide` か `aiagent-check-setup` から入る
- lesson は `aiagent-lesson-runner` に `start-*` を渡して進める
- safety は `workspace-write + on-request` と repo hooks を基準にする

## Cursor のコンテキスト指定

### @ メンション
- `@file`: 特定ファイルをコンテキストに追加
- `@folder`: フォルダ全体を参照
- `@web`: Web 検索結果を参照
- `@docs`: ドキュメントを参照
- `@codebase`: コードベース全体を検索

### `.cursorrules`
プロジェクトルートに配置するルールファイル。Cursor の AI 動作をカスタマイズ:
```
- 日本語で回答する
- コメントは日本語で書く
- TypeScript を使用する
```

## Codex の repo ルール

- ルートの `AGENTS.md` を参照する
- tool 固有の入口は `skills/` に集約する
- `.cursor/commands/*` は参考資料として扱う
