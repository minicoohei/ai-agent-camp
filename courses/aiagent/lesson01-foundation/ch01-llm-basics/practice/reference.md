# 参照テキスト: LLM 基礎

## LLM（Large Language Model）とは

大規模言語モデル（LLM）は、大量のテキストデータで訓練された深層学習モデルです。テキストの生成、翻訳、要約、質問応答など、幅広い自然言語処理タスクを実行できます。

## Transformer アーキテクチャ概要

2017年の論文「Attention Is All You Need」で提案されたアーキテクチャ。

### 主要コンポーネント
- **Self-Attention（自己注意機構）**: 入力シーケンス内の各トークン間の関連度を計算
- **Multi-Head Attention**: 複数の注意ヘッドで異なる観点から情報を捕捉
- **Feed-Forward Network**: 各位置の情報を非線形変換
- **Positional Encoding**: トークンの位置情報を付与

### 推論の仕組み
1. 入力テキストをトークンに分割
2. トークンをベクトル（Embedding）に変換
3. Transformer 層を通して文脈を理解
4. 次のトークンの確率分布を計算
5. 確率に基づいてトークンを選択（デコーディング）
6. 完了条件まで 3-5 を繰り返す

## 訓練プロセス

### 事前学習（Pre-training）
- 大量のテキストデータ（数兆トークン）で学習
- 「次のトークンを予測する」タスクで汎用的な言語理解を獲得
- 数千〜数万の GPU で数ヶ月かけて実行

### ファインチューニング
- 特定タスクのデータで追加学習
- 事前学習の知識を活かしつつ、タスク固有の能力を向上

### RLHF（人間のフィードバックによる強化学習）
- 人間の評価者がモデルの出力を比較・評価
- 評価データから報酬モデルを学習
- 報酬モデルを使って LLM を最適化
- 安全性・有用性・正直さの向上が目的

## 重要な概念

### コンテキストウィンドウ
モデルが一度に処理できるトークン数の上限。Claude 4 は 200K トークン、GPT-4 は 128K トークンなど。

### Temperature（温度パラメータ）
出力のランダム性を制御するパラメータ。0に近いほど決定的、1に近いほど多様な出力。

### Hallucination（ハルシネーション）
モデルが事実と異なる情報を自信を持って生成する現象。LLM の根本的な課題の一つ。
