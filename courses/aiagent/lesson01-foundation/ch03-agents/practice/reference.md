# 参照テキスト: エージェント

## エージェントの定義

AIエージェントとは、環境を観察し、自律的に判断して行動するAIシステムです。単なるチャットボットとの違いは、ツールを使って実際のアクションを実行できる点にあります。

## Observe-Think-Act ループ

エージェントの基本動作サイクル:

1. **Observe（観察）**: 環境からの情報を取得
   - ユーザーの指示を受け取る
   - ファイルシステムやAPIからデータを読み取る
   - 前回のアクション結果を確認する

2. **Think（思考）**: 情報を分析し、次のアクションを決定
   - 目標達成のための計画を立てる
   - 利用可能なツールを選択する
   - 実行順序を決める

3. **Act（行動）**: 決定したアクションを実行
   - ツールを呼び出す（ファイル操作、API呼び出し等）
   - 結果を確認する
   - 必要に応じてループを繰り返す

## 自律性レベル（5段階）

| レベル | 名称 | 説明 | 例 |
|--------|------|------|-----|
| 1 | アシスタント | 質問に答えるだけ | ChatGPT（基本） |
| 2 | ツール使用 | 指示に従いツールを実行 | Claude Code（基本） |
| 3 | 計画実行 | 計画を立ててツールを連鎖実行 | Claude Code（複雑タスク） |
| 4 | 自律タスク | 目標を受けて自律的に完遂 | Devin、Claude sub-agent |
| 5 | 完全自律 | 目標設定から自律的に行動 | 研究段階 |

## 主要なエージェントパターン

### ReAct（Reasoning + Acting）
思考と行動を交互に行うパターン。各ステップで「なぜそのアクションを取るか」を明示的に推論してから行動する。

### Plan-and-Execute
最初に全体計画を立て、計画に沿ってステップを順次実行するパターン。修正が必要な場合は計画を更新する。

### Tool Use
LLM が適切なツール（関数）を選択して呼び出すパターン。ツールの実行結果を次の推論に活用する。

### Multi-Agent
複数のエージェントが協調して問題を解決するパターン。各エージェントに専門的な役割を割り当てる。

## Claude Code のエージェント機能

- **ファイル操作**: 読み取り、書き込み、編集、削除
- **コマンド実行**: bash コマンドの実行
- **Web 検索**: インターネットからの情報取得
- **サブエージェント**: Task ツールで専門エージェントに委任
- **MCP ツール**: 外部サービスとの連携
