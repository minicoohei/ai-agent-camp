# 推奨拡張機能リスト

## 必須（10個）

### 1. Japanese Language Pack
- **ID**: `ms-ceintl.vscode-language-pack-ja`
- **説明**: VS Code / Cursor の日本語化
- **用途**: メニューやエラーメッセージを日本語で表示

### 2. Python
- **ID**: `ms-python.python`
- **説明**: Python 言語サポート（IntelliSense、デバッグ、リンター）
- **用途**: Python スクリプトの開発・実行

### 3. Pylance
- **ID**: `ms-python.vscode-pylance`
- **説明**: Python の高速な型チェック・補完エンジン
- **用途**: Python コードの品質向上

### 4. ESLint
- **ID**: `dbaeumer.vscode-eslint`
- **説明**: JavaScript/TypeScript のリンター
- **用途**: コード品質チェック

### 5. Prettier
- **ID**: `esbenp.prettier-vscode`
- **説明**: コードフォーマッター（JS, TS, HTML, CSS, JSON, YAML 対応）
- **用途**: コードの自動整形

### 6. GitLens
- **ID**: `eamodio.gitlens`
- **説明**: Git の詳細情報を表示（行ごとの変更履歴、ブランチ比較）
- **用途**: Git 操作の効率化

### 7. GitHub Copilot
- **ID**: `github.copilot`
- **説明**: AI コード補完
- **用途**: コーディング補助（Cursor の AI 機能と併用可能）

### 8. YAML
- **ID**: `redhat.vscode-yaml`
- **説明**: YAML 言語サポート（バリデーション、補完）
- **用途**: GitHub Actions、設定ファイルの編集

### 9. Markdown All in One
- **ID**: `yzhang.markdown-all-in-one`
- **説明**: Markdown のショートカット、プレビュー、目次生成
- **用途**: ドキュメント作成

### 10. Path Intellisense
- **ID**: `christian-kohler.path-intellisense`
- **説明**: ファイルパスの自動補完
- **用途**: import文やファイル参照の入力効率化

## 推奨オプション

### Live Server
- **ID**: `ritwickdey.liveserver`
- **説明**: HTML ファイルのライブプレビュー
- **用途**: 教材 HTML のプレビュー確認

### Thunder Client
- **ID**: `rangav.vscode-thunder-client`
- **説明**: REST API クライアント（Postman 代替）
- **用途**: API のテスト・デバッグ

### indent-rainbow
- **ID**: `oderwat.indent-rainbow`
- **説明**: インデントを色分け表示
- **用途**: YAML や Python のインデント確認
