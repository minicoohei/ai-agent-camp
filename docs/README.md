## 📖 ドキュメント活用ガイド

### コマンドリファレンスの使い方

1. **コマンド一覧から検索**
   - 目次から Module や カテゴリを選択
   - コマンド名から直接検索（Ctrl+F）

2. **パラメータを確認**
   - 各コマンドの「パラメータ」セクションを参照
   - 必須・オプショナルの判別

3. **使用例を参考にする**
   - 複数の使用例が記載されている
   - 自分のユースケースに合わせてカスタマイズ

4. **トラブルシューティング**
   - エラーが出たら troubleshoot.md も参照

---

### スキルリファレンスの使い方

1. **スキル一覧から選択**
   - 画像生成、データ分析など用途別に分類
   - 目的に合ったスキルを見つける

2. **インストール方法を確認**
   - 必須パッケージと API キーを確認
   - インストール手順に従う

3. **パラメータと使用例を確認**
   - 全パラメータ一覧表で仕様を把握
   - 複数の使用例で活用方法を学ぶ

4. **問題が発生したら**
   - 各スキルの「トラブルシューティング」セクション参照
   - troubleshoot.md も確認

---

### トラブルシューティングの使い方

1. **エラーメッセージを確認**
   - エラーメッセージの内容から該当セクションを探す
   - 「問題XX」の形式で整理されている

2. **原因と解決方法を読む**
   - なぜエラーが発生するのか理解する
   - ステップバイステップの解決方法に従う

3. **その他の原因を確認**
   - 「チェックリスト」で見落としがないか確認
   - 「予防策」で将来の問題を防ぐ

4. **FAQ を活用**
   - よくある質問コーナーで解答を見つける
   - ベストプラクティスを学ぶ
