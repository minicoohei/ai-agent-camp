# 青空商事・見積確認の演習

会社・案件・金額はすべて架空です。Python 3.10以上の標準ライブラリだけを使用します。教材のstarterを新しい作業フォルダへコピーしてから編集してください。

## 固定の見積ルール

1. 小計はすべての明細の「単価×数量」の合計。
2. 小計が100,000円以上なら5%値引き。値引き後は1円単位で四捨五入。
3. 税は値引き後金額の10%を1円単位で四捨五入。
4. 税込合計は値引き後金額＋税。

税率は演習用の仮定です。入力は0以上の整数の単価・数量に限定します。負数、通貨換算、請求書発行は対象外です。

## 始め方

`python3 checks.py`（Windowsは `py -3 checks.py`）を実行してください。4テスト中2失敗が初期状態です。`quote.py` には最後の明細と値引き境界の不具合を意図的に入れています。`checks.py` を変更せず修正します。

| テスト対象 | 期待結果 |
| --- | --- |
| 20,000円×2 + 5,000円×3 | 小計55,000円 |
| 小計100,000円 | 値引き後95,000円 |
| 小計99,999円 | 値引きなし |
| 40,000円×2 + 30,000円×1 + 0円×1 | 小計110,000円、値引き後104,500円、税10,450円、税込114,950円 |

最後のテストは、最後の行が0円でも境界以外の計算が保たれるかを見るものです。最後の明細漏れは1つ目で検出します。

`cases.json` はSkillと画面の入力、`skills/quote-review/` は再利用する手順、`design/` は外部接続のない静的なデザイン見本です。作業記録は自分で `evidence/` を作成して保存します。認証情報をこのフォルダへ入れないでください。
