# 見積確認の手順

1. `id`、`company`、`items`、`quoted_total` があるか確認する。`items` は単価・数量の組で、どちらも0以上の整数に限る。不足、不正な型、対象外の値があれば推測せず確認待ちにする。
2. **すべての明細**の単価×数量を足す。
3. 小計が100,000円**以上**なら95%を掛けて1円単位で四捨五入する。未満ならそのまま。
4. 値引き後金額の10%を1円単位で四捨五入して税とする。小数計算にはDecimalとROUND_HALF_UP相当を使う。
5. 値引き後金額＋税を計算額とし、「提示額−計算額」を差とする。差0なら「一致」、0以外は「要修正」。これは演習上の判定であり、取引の承認ではない。

演習用の `quote.py` は未修正かもしれないため、その出力を正解として転記しない。このルールから独立して計算し、各式を残す。

## 出力する見出し

- 入力：ファイル名、案件ID、会社名（架空）
- 手順：Skill名とversion
- 計算根拠：各明細、小計、値引き後、税、合計
- 差額：提示額、計算額、提示額−計算額
- 判定：一致／要修正／確認待ち
- 未確認事項：なければ「なし」。実行できなかった確認があれば具体的に記載

## 確認

入力IDを取り違えていないか、最後の明細を含めたか、境界の「以上」が合っているか、前の案件の値が混ざっていないかを確認して完了する。
