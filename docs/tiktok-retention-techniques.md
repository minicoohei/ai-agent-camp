# TikTok 視聴維持率テクニック集

## 1. Split-Screen / Subway Surfers型（画面分割型）

### 概要
画面を上下に分割し、上半分にメインコンテンツ（語り、教育、ストーリー等）、下半分にゲーム実況（Subway Surfers、Minecraft parkour、Slime videos等）を配置する手法。

### なぜ効くのか
- **デュアルアテンション**: 視聴者の脳が2つの刺激を同時処理→離脱しにくい
- **"Satisfying"効果**: ゲーム映像の反復的な動きが心地よく、スクロールを止める
- **退屈な瞬間をカバー**: メインコンテンツが単調でも下半分の動きが視聴を維持
- TikTokアルゴリズムはwatch timeを最重要視するため、維持率UP→推奨UP

### 構成
- **画面比率**: 上60% / 下40%、または上55% / 下45%
- **上半分**: テキスト+ナレーション（教育系）、顔出し語り、Reddit投稿の読み上げ等
- **下半分**: Subway Surfers、Minecraft parkour、Satisfying slime、Soap cutting
- **音声**: メインコンテンツのナレーション/TTS（下のゲーム音は無音orミュート）

### 量産適性: ★★★★★
- 上半分はAIテキスト+TTS、下半分はストック映像ループ
- 50アカウント運用に最適（バリエーション無限）

## 2. Hook手法（冒頭3秒）

### 2a. テキストHook
| パターン | 例 | 効果 |
|----------|-----|------|
| **疑問型** | 「なぜ日本人は○○なのか？」 | 好奇心を刺激 |
| **衝撃事実型** | 「99%の人が知らない...」 | FOMO（見逃し恐怖） |
| **POV型** | 「POV: あなたは○○を発見した」 | 没入感 |
| **Wait for it型** | 「最後まで見て」「3つ目がヤバい」 | 最後まで見させる |
| **対立型** | 「○○は嘘です」 | 論争→コメント誘導 |
| **数字型** | 「5つの方法で○○」 | 構造が明確で安心感 |

### 2b. 映像Hook
- **冒頭にクライマックス**: 最も衝撃的なシーンを0秒に配置、その後「話は3時間前に遡る...」
- **バイラルクリップ挿入**: 冒頭1-2秒に無関係だがインパクトのある映像→本題へ
- **ビフォーアフター**: 結果を先に見せる → 過程を解説

### 2c. 音声Hook
- 冒頭に「ピッ」「ボーン」等のSE（効果音）で注意を引く
- TikTokトレンド音源の冒頭を使う（アルゴリズムがトレンド音源を優遇）

## 3. 視聴維持テクニック

### 3a. ループ構造（Loop Structure）
動画の最後が最初にシームレスに繋がる。視聴者が気づかず2周目に突入→再生回数×2。
- **実装**: 最後のフレーム=最初のフレーム、BGMもループ
- **量産適性**: ★★★★（テンプレート化しやすい）

### 3b. 段階的情報開示（Progressive Disclosure）
「1つ目は...」→「2つ目は...」→「3つ目が一番ヤバい」
リストを順番に見せて最後に最強の項目を配置。

### 3c. カウントダウン / ランキング
「第5位...第4位...」と進めて1位まで引っ張る。
- 逆に「第1位」から始めて「でも実は0位がある」パターンも

### 3d. BGM BPM同期
- **ハイテンポBGM** (120-140BPM) でカットを合わせる
- ビートドロップに合わせてシーン転換
- TikTokのトレンド音源を使うとアルゴリズム加点

### 3e. テキストの段階表示
一度に全文表示ではなく、1行ずつ出す（ポップイン）
→ 次の行を読みたくて視聴継続

### 3f. コメント誘導テクニック
- 「間違いを探せ」→ コメント欄で議論
- 「あなたはどっち派？」→ 二択で意見表明
- わざと小さなミスを入れる → 指摘コメントが増える
- コメント数がアルゴリズムで高評価→推奨UP

## 4. ジャンル別 勝ちパターン

### Teaching（教育/知識系）
- **構成**: Hook(1s) → 問題提起(3s) → 解説(15-25s) → まとめ/CTA(3s)
- **テロップ**: 大きく太いゴシック、原色（赤/黄/緑）、中央配置
- **ペース**: Fast（1-3秒/カット）
- **キー**: 「知らないと損する」系のフレーミング

### Intro（商品紹介/レビュー）
- **構成**: 結果を先に見せる → 開封/使用 → 感想/比較
- **テロップ**: 商品名+価格を常時表示
- **テクニック**: ASMR的なクローズアップ音声

### ストーリーテリング
- **構成**: Hook → 状況設定 → 問題 → 転換 → 結末
- **テロップ**: サブタイトル的に下部配置
- **テクニック**: TTS（AI音声）+ テキストスクロール + 背景動画

### Before/After
- **構成**: After(1s) → Before(3s) → 過程(15s) → After(3s)
- **テクニック**: 同じアングルでの比較、スワイプトランジション

## 5. 2025-2026年トレンド

### AI生成コンテンツの成功パターン
- **Faceless channels（顔出しなし）**: AI音声 + AI画像 + テキストオーバーレイ
- **Reddit読み上げ + ゲーム背景**: r/AITA等のストーリー + Minecraft
- **AI解説系**: 歴史、科学、雑学をAI生成画像で視覚化
- **ダークファクト系**: 「知ると怖い○○」+ 不気味なAI画像

### 日本 vs 海外の違い
| 項目 | 日本 | 海外 |
|------|------|------|
| テロップ | 必須、大きく | あってもなくても |
| 顔出し | 少ない傾向 | 多い |
| 尺 | 15-30秒 | 30-60秒 |
| BGM | J-POPアレンジ | トレンド音源 |
| フォント | ゴシック太字+縁取り | Sans-serif白 |

### 50アカウント量産に最適なフォーマット（優先度順）

1. **Split-screen教育型** ★★★★★
   - 上: AI生成テキスト+TTS / 下: ゲーム映像ストック
   - ジャンル横展開が容易（歴史、科学、心理学、雑学...）

2. **Reddit/2ch読み上げ型** ★★★★★
   - テキストスクロール + TTS + 背景動画
   - コンテンツソースが無限

3. **ランキング/リスト型** ★★★★☆
   - 「○○ランキングTOP5」
   - AI画像 + テロップ + TTS

4. **ダークファクト/雑学型** ★★★★☆
   - 「知ると怖い」「衝撃の事実」
   - AI画像のバリエーションで量産

5. **Before/After型** ★★★☆☆
   - 実際の素材が必要な場合あり
   - AI生成のみだと不自然になりがち

## 6. 実装メモ（パイプラインへの組み込み）

### scriptwriterに組み込むべきフォーマット
```json
{
  "formats": [
    "split_screen_teaching",
    "reddit_story",
    "ranking_list",
    "dark_facts",
    "before_after",
    "loop_video"
  ]
}
```

### video-editorに必要な新機能
- Split-screen合成（上下分割 + 背景動画レイヤー）
- ループ検出/ループ生成
- BPM同期カット（音楽のビートに合わせたシーン転換）
- テキストのポップインアニメーション（既にCaption.tsxで部分実装済み）

### storyboard-generatorの改善点
- フォーマット別のプロンプトテンプレート
- Split-screen用の上半分のみのフレーム生成
- ランキング型のナンバリング付きフレーム
