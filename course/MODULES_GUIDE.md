## How to Use Each Format

### Index Pages (Module Overview)
- **Best for**: Getting started with a module, understanding learning objectives
- **Features**:
  - Hero section with module description
  - Learning objectives and lessons
  - Hands-on exercises with code examples
  - Resources and external links
  - Navigation to previous/next modules
- **Interactive**: Code copy-to-clipboard buttons

### Slides (Interactive Presentation)
- **Best for**: Learning key concepts, classroom presentation
- **Features**:
  - Full-screen slides
  - Keyboard navigation (← → arrow keys)
  - Slide sidebar for quick navigation
  - Progressive disclosure of concepts
  - Code examples integrated
- **Navigation**: Click slide list or use arrow keys

### Manual (Hands-on Guide)
- **Best for**: Step-by-step implementation, reference
- **Features**:
  - Sidebar navigation for quick access to topics
  - Detailed step-by-step instructions
  - Tables for reference information
  - Tips and troubleshooting sections
  - Code examples with copy functionality
- **Navigation**: Click sidebar topics or scroll

## Image Asset Convention

### 正規配置パス

すべての教材用画像は以下のパスに配置すること:

```text
course/assets/images/{category}/filename.png
```

**`course/images/` への新規配置は禁止。** 既存ファイルも `course/assets/images/` に移行済み。

### カテゴリ命名規則

| 用途 | カテゴリ名 | 例 |
|------|-----------|-----|
| Foundation教材 | トピック名 | `llm-basics/`, `agents/`, `rag/`, `security/` |
| モジュール教材 | `module{N}/` | `module1/`, `module12/` |
| セットアップ | `setup/assets/images/` | `course/setup/` 配下で独立管理（セットアップ手順は他教材と更新サイクルが異なるため） |

### ファイル命名規則

- **ケバブケース**（小文字 + ハイフン区切り）: `sample-banner-x.png`
- **カテゴリ接頭辞**: 概要画像は `module{NN}-` で始める（例: `module02-diagram-tools-comparison.png`）
- **アノテーション付き**: `-annotated` サフィックス（例: `model-settings-annotated.png`）
- **ソースファイル**: 元画像は `source/` サブディレクトリに配置

### 画像の参照

画像は `course/assets/images/` に配置し、外部サイト（aiagent-course）側から参照します。

## 教材ページの管理

教材ページ（HTML）は外部サイト `https://ai-agent.camp/` で管理されています（aiagent-course リポジトリ）。
ai-agent-camp 側では、レッスンコマンドと `courses/` 内のYAMLメタデータのみを管理します。

### 新規モジュール追加時

1. `courses/aiagent/lesson03-core/` に chapter YAML を追加
2. `courses/lessons.manifest.yaml` にレッスンエントリを追加
3. `.claude/commands/lesson/` と `.cursor/commands/lesson/` にコマンドファイルを作成
4. 教材ページリンクは `https://ai-agent.camp/ja/course/module-{N}` を使用

### Styling
- Primary colors in CSS variables: `--primary-navy`, `--accent-blue`, etc.
- Font variables: `--font-sans`, `--font-mono`
- Spacing: `--space-1` to `--space-16` (0.25rem to 4rem)
- Shadows and transitions already defined

## CursorBootcamp YAML 構造

本コースは `courses/aiagent/` 配下に YAML メタデータレイヤーを持ちます。各モジュールの `chapter.yaml` が既存 HTML 教材を `externalContent` で参照する構成です。

```
courses/aiagent/
├── course.yaml
├── lesson01-foundation/ (11 chapters: LLM基礎 ～ AIセキュリティ)
├── lesson02-setup/ (3 chapters: 環境 / 拡張機能 / API設定)
└── lesson03-core/ (13 chapters: module01-banner ～ module18-pm-sysdef)
```

詳細は `courses/aiagent/course.yaml` および各 `lesson.yaml` を参照してください。
