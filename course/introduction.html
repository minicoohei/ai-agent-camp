3つのツールに対応

この講座は3つのAIツールに対応しています。どれを使っても同じ内容を学べます。

Cursor

GUI / IDE

Visual Studio Code ベースのAI統合IDE。画面を見ながら操作でき、初心者に最もわかりやすいツールです。

File > Open Folder で ai-agent-camp を開く

Claude Code

CLI / ターミナル

ターミナル上で動作するCLIツール。高速でパワフル、複雑なタスクの自動化に適しています。

cd ~/ai-agent-camp && claude

Codex

CLI / Skill

OpenAI の CLI ツール。AGENTS.md と Lesson Runner スキルを入口に学習を進めます。

AGENTS.md から開始

Web教材とデスクトップ環境の関係: AI Agent Camp の教材サイト（Web）で概念を学び、ai-agent-camp（デスクトップ開発環境）でコマンドを実行して実践します。

まずやること

Step 1: ツールをインストール

Cursor、Claude Code、Codex のいずれかをインストールします。

Step 2: ai-agent-camp を開く

Cursor の場合:

File > Open Folder → ~/ai-agent-camp を選択

Claude Code の場合:

cd ~/ai-agent-camp && claude

Step 3: 環境をチェック

Cursor / Claude Code:

/check-setup

AIが自動で Python、Node.js、Git、API キーの設定を確認・修復します。

Step 4: 最初のレッスンを開始

/start-0-1

セットアップの確認から始まります

学習の3つの原則

1

順番にこだわらない

全モジュールを順番に進める必要はありません。興味のあるモジュールから始めて大丈夫です。

2

手を動かして体験する

コマンドを実行して、AIと対話しながら成果物を作りましょう。読むだけでは身につきません。

3

成果物を業務に活用する

レッスンで作ったバナー、資料、分析結果をそのまま実務に使ってみてください。
