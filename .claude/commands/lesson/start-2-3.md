## ⚠️ よくあるトラブルと解決方法

AskUserQuestion（AskQuestion）でトラブル内容を選んでもらい、押すだけで案内します。

**AskQuestionの設定例:**
```json
{
  "title": "トラブル内容を選択",
  "questions": [{
    "id": "trouble",
    "prompt": "当てはまる内容を1つ選んでください",
    "options": [
      {"id": "trouble_1", "label": "システム構成図が複雑すぎる"},
      {"id": "trouble_2", "label": "ロードマップの期間が分かりにくい"},
      {"id": "trouble_3", "label": "比較表で自社の優位性が伝わらない"},
      {"id": "trouble_4", "label": "提案の図表セットに一貫性がない"}
    ]
  }]
}
```


### トラブル1: 「システム構成図が複雑すぎる」
**原因**: 一つの図に全てを詰め込んでいる
**解決プロンプト**:
```
システム構成図を以下の3つに分割してください：
1. 概要レベル（全体像、主要コンポーネントのみ）
2. 詳細レベル（各サービスの内部構成）
3. データフロー（データの流れに特化）
```

### トラブル2: 「ロードマップの期間が分かりにくい」
**原因**: タイムラインの表現が曖昧
**解決プロンプト**:
```
ロードマップに以下を追加してください：
- 明確な日付または期間のラベル
- 各フェーズの開始・終了を示すマイルストーン
- 重複する作業がある場合はガントチャート形式に
```

### トラブル3: 「比較表で自社の優位性が伝わらない」
**原因**: 視覚的な強調が不足
**解決プロンプト**:
```
自社の優位性を強調するために：
- 自社の列を目立つ色（青や緑）で塗りつぶす
- 優れている項目に「推奨」「No.1」などのバッジを追加
- 競合より優れている数値を大きなフォントで表示
```

### トラブル4: 「提案の図表セットに一貫性がない」
**原因**: 各図表を個別に作成している
**解決プロンプト**:
```
4つの図表すべてで以下を統一してください：
- カラーパレット: 青（#0066CC）を基調
- フォント: サンセリフ、見出しは太字
- レイアウト: 左上にタイトル、右下にページ番号
- ロゴまたはブランド要素を配置
```
