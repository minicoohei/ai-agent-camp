# Cursorの使い方 研修: 画像を読み込んで要約を作成する

## このコマンドでやること

**ドラッグ＆ドロップ** または **@** で画像をAIに渡し、内容の要約や説明を得ます。

| 項目 | 内容 |
|------|------|
| ゴール | 画像を渡して要約・説明のテキストを得る |
| 所要時間 | 約10分 |
| 用意するもの | 任意の画像（スクリーンショット・図表・スライド1枚など） |
| 教材ページ | [Cursorの使い方](../../../course/index.html) |

---

## Step 1: 画像を用意し、コンテキストの渡し方を確認する

1. **画像を1枚用意する**
   - スクリーンショット、図表、スライドの1枚、写真など、何でもよい。
   - ワークスペース内の画像でも、デスクトップやダウンロードフォルダの画像でも可。

2. **渡し方の確認**
   - **ドラッグ＆ドロップ**: 画像ファイルをチャット入力欄にドラッグして放す。
   - **@ で指定**: チャットで @ を入力し、画像ファイルを選択する。

---

## Step 2: 画像をチャットに渡す（ドラッグ＆ドロップまたは @）

**方法A: ドラッグ＆ドロップ（推奨）**

1. 画像ファイルが入っているフォルダを開く。
2. 画像ファイルを Cursor のチャット入力欄に **ドラッグ＆ドロップ** する。
3. 画像がチャットに追加された状態になる。

**方法B: @ で指定する**

1. Cursorのチャット入力欄で **@** を入力する。
2. 一覧から「File」を選び、用意した **画像ファイル** を選択する。
3. 画像がコンテキストに追加された状態になる。

---

## Step 3: 指示を送って要約・説明を得る

次のいずれかの指示を入力して送信する。

**指示例:**

```
この画像の内容を要約してください。
```

または

```
この図（画像）が説明していることを箇条書きで教えてください。
```

**期待される結果**: 画像の内容に基づいた要約や説明が返る。

**発展**: 「3行で」「キーワードだけ」など条件を足して再度依頼してもよい。
