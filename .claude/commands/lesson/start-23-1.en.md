# Lesson 23-1: LINE Official Account Operations Introduction

## What You'll Do

Learn the architecture for operating a LINE Official Account that your organization fully controls, using **Cloudflare Workers** and the **LINE Messaging API**.

## Prerequisites

- Be able to create a LINE Official Account and LINE Developers account
- Have a Cloudflare account
- Run `/setup-line-harness` first if setup is not complete

## Goals

1. Understand the overall setup for LINE Developers Console, webhooks, and secret management
2. Confirm the auto-register pattern for importing existing friends
3. Explain when to use auto replies, scenario delivery, and broadcasts
4. Confirm operations points for D1, line-harness MCP, and the Slack bridge
