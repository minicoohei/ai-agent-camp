# 🎓 Lesson 12-5: ファイル取得と表示

## 📍 このセッションでやること

**Lesson 12-5** へようこそ！

| 項目 | 内容 |
|------|------|
| ゴール | Notion 上の **ファイルブロック・添付・エクスポート可能な URL** を特定し、エージェントが **内容を確認・ユーザーに分かりやすく表示** できる |
| 所要時間 | 約30分 |
| 使うスキル | Notion MCP（ページ／ブロック取得）、必要に応じて公式 API |
| 前提条件 | `/start-12-4` まで完了、対象ページへのアクセス権あり |
| 教材ページ | [Module 12: Notion](https://ai-agent.camp/ja/course/module-12) を並行参照 |

**このセッションの流れ:**
1. 対象ページのブロック一覧から **ファイル / PDF / 画像** を含むブロックを特定する
2. 利用中の MCP または API で **取得可能な形式**（テキスト抽出・一時 URL・ローカル保存）を選ぶ
3. バイナリをチャットにそのまま貼らず、**ファイル名・種類・要約・参照リンク** として返す

セッション終了時には、「どこにファイルがあるか → どう取るか → ユーザーにどう見せるか」が再現できます。

> **💡 ヒント**: AIの応答が途中で止まった場合は「続きを表示して」と入力すると再開します。

> **🔒 秘密情報**: ダウンロード URL やトークンをログやチャットに生で貼らないでください。

## 🚀 Step 1: ファイルブロックの特定

エージェントは次を実行します。

1. ユーザーから **ページ URL またはページ ID** を確認する
2. MCP / `retrieve block children` 等でブロックを走査し、`type: file` や埋め込みに相当するブロックを列挙する
3. ユーザーに「ファイル名・ブロック種別」のリストを短く返す

**ユーザーへのプロンプト例:**
```text
この Notion ページ内のファイル添付をすべて列挙し、
それぞれ取得方法（MCP で取れるか、ブラウザで開くか）を一言ずつ添えてください。
ページ: <URL>
```

---

## 🚀 Step 2: 取得とローカル確認

1. MCP ツールの説明に従い、**ファイル内容の取得** または **ユーザーのローカルへの保存** を試みる
2. ツールがバイナリのみ返す場合は、**ファイルサイズとハッシュ** だけ報告し、開く手順をユーザーに任せる
3. テキスト／Markdown に変換できる場合は **先頭数百文字** と見出しだけ抜粋する

---

## 🚀 Step 3: チャットでの「表示」

**必須ルール:**
- 画像: 可能であれば `![](URL)` やファイルパスを **短く** 示す（巨大 base64 は避ける）
- PDF: ページ数・目次レベルの要約のみ（全文 OCR はユーザーが明示したときのみ）
- **完了報告** に「何のファイルを」「どこまで読んだか」を含める
