# Lesson 24-1: Introduccion a la integracion con Salesforce CLI

## Lo que hara en esta sesion

Aprenda los conceptos basicos de login en navegador, consulta de datos con SOQL, actualizaciones masivas por CSV y retrieve/deploy de metadatos usando **Salesforce CLI (`sf`)**.

## Requisitos previos

- Poder iniciar sesion en una organizacion de Salesforce
- Tener disponible la CLI `sf`
- Ejecutar `/setup-salesforce` primero si la configuracion no esta completa

## Objetivos

1. Confirmar el flujo de `sf org login web` y gestion de alias
2. Buscar datos de Account / Opportunity con `/module-24-soql`
3. Entender el flujo CSV para insert / update / upsert
4. Confirmar el flujo de `/module-24-metadata-retrieve` y `/module-24-metadata-deploy`
