## 🚀 Step 1: メールシーケンスの基本概念

メールシーケンスとは、特定のトリガーに応じて自動送信されるメールの連続です。

**主なシーケンスタイプ:**
| タイプ | 目的 | 例 |
|--------|------|-----|
| ウェルカム | 新規登録者の歓迎 | サービス紹介 → 使い方ガイド → Tips |
| オンボーディング | 利用開始の支援 | セットアップ → 初回操作 → 応用 |
| リードナーチャリング | 見込み顧客の育成 | 課題提起 → 解決策 → 事例 → CTA |
| リエンゲージメント | 離脱ユーザーの復帰 | 近況報告 → 新機能案内 → 特典 |

## 🚀 Step 3: メールテンプレートの作成

設計したシーケンスの各メールについて、テンプレートを作成します。

**テンプレートの構成要素:**
- **件名**: 開封率を左右する最重要要素
- **プレヘッダー**: 件名の補足（メールクライアントのプレビューに表示）
- **本文**: メインコンテンツ
- **CTA**: 行動喚起ボタン/リンク

**プロンプト例:**
```text
先ほど設計したウェルカムシーケンスの1通目のメールテンプレートを作成してください。
件名は3パターン提案し、本文はHTML形式で出力してください。
```

## 🚀 Step 4: 送信タイミングと件名戦略

**送信タイミングのベストプラクティス:**
| メール | タイミング | 理由 |
|--------|-----------|------|
| 1通目 | 登録直後 | 興味が最も高い瞬間 |
| 2通目 | 翌日 | 初回操作のフォロー |
| 3通目 | 3日後 | 習慣形成の支援 |
| 4通目 | 7日後 | 価値の再確認 |
| 5通目 | 14日後 | アップグレード提案 |

**件名のA/Bテスト戦略:**
- パーソナライゼーション: 「{名前}さん、」を入れるか
- 緊急性: 「期間限定」「残り3日」
- 疑問形: 「〜でお困りですか？」
- 数字: 「3つのステップで」

---

## ⚠️ よくあるトラブルと解決方法

| トラブル | 解決策 |
|---------|--------|
| シーケンスの構成が決まらない | テンプレートから始めて段階的にカスタマイズ |
| メール数が多すぎ/少なすぎ | ゴールに対する最小ステップ数で設計 |
| 件名のアイデアが浮かばない | 競合のメールを参考にするか、AI に複数案を提案させる |
