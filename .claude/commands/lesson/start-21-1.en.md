# Lesson 21-1: Figma Integration Introduction

## What You'll Do

Learn how to combine the **official Figma MCP** and the **Serendie design system MCP** so an AI agent can read and write Figma, then continue into UI implementation that follows the design system.

## Prerequisites

- Have a Figma account
- Use interactive mode because browser OAuth is required
- Run `/setup-figma` first if setup is not complete

## Goals

1. Explain the different roles of the official Figma MCP and Serendie MCP
2. Confirm the plugin installation and OAuth authentication flow
3. Understand how to import the Serendie UI Kit into a team and publish it as a library
4. Confirm the basic flow from a Figma selection to code implementation
