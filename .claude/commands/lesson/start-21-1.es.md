# Lesson 21-1: Introduccion a la integracion con Figma

## Lo que hara en esta sesion

Aprenda a combinar el **MCP oficial de Figma** y el **MCP del sistema de diseno Serendie** para que un agente de IA pueda leer y escribir en Figma, y continuar hacia una implementacion de UI alineada con el sistema de diseno.

## Requisitos previos

- Tener una cuenta de Figma
- Usar modo interactivo porque se requiere OAuth en el navegador
- Ejecutar `/setup-figma` primero si la configuracion no esta completa

## Objetivos

1. Explicar los roles del MCP oficial de Figma y del MCP de Serendie
2. Confirmar el flujo de instalacion del plugin y autenticacion OAuth
3. Entender como importar Serendie UI Kit a un equipo y publicarlo como biblioteca
4. Confirmar el flujo basico desde una seleccion de Figma hasta la implementacion de codigo
