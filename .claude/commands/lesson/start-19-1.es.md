# Lesson 19-1: Integración con Microsoft Office (Outlook) - Introducción

## Lo que hará en esta sesión

Aprenda los conceptos básicos para operar el correo y el calendario de Outlook utilizando **Microsoft 365 CLI (m365)**.

> **Note**: Esta lección está en preparación. El contenido se añadirá en el futuro.

## Requisitos previos

- Tener una cuenta de Microsoft 365
- Tener m365 CLI instalado

## Objetivos

1. Configuración de autenticación de m365 CLI
2. Obtener la lista de correos de Outlook
3. Búsqueda y filtrado de correos
4. Obtener eventos del calendario
