# Lesson 23-1: Introduccion a la operacion de LINE Official Account

## Lo que hara en esta sesion

Aprenda la arquitectura para operar una cuenta oficial de LINE totalmente controlada por su organizacion, usando **Cloudflare Workers** y **LINE Messaging API**.

## Requisitos previos

- Poder crear una cuenta oficial de LINE y una cuenta de LINE Developers
- Tener una cuenta de Cloudflare
- Ejecutar `/setup-line-harness` primero si la configuracion no esta completa

## Objetivos

1. Entender la configuracion general de LINE Developers Console, webhooks y gestion de secretos
2. Confirmar el patron auto-register para importar amigos existentes
3. Explicar cuando usar respuestas automaticas, entregas por escenario y broadcasts
4. Confirmar puntos de operacion para D1, line-harness MCP y el puente con Slack
