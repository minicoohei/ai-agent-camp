# Lesson 21-1: Figma 連携 入門

## このセッションでやること

**Figma 公式 MCP** と **Serendie デザインシステム MCP** を組み合わせて、AI エージェントが Figma を読み書きし、デザインシステムに沿った UI 実装まで進める流れを学びます。

## 前提条件

- Figma アカウントを持っていること
- ブラウザ OAuth が使える対話モードで進めること
- 必要に応じて `/setup-figma` を先に実行すること

## ゴール

1. Figma 公式 MCP と Serendie MCP の役割を説明できる
2. Figma プラグイン導入と OAuth 認証の流れを確認する
3. Serendie UI Kit をチームへ取り込み、ライブラリ公開の要点を理解する
4. Figma 選択範囲からコード実装へつなげる基本フローを確認する
