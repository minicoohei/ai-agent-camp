# Lesson 25-1: Introducción a la integración con Google Ads

## Lo que hará en esta sesión

Aprenda a manejar **Google Ads API** de forma segura desde un agente de IA: jerarquía de cuentas, Developer Token / OAuth, llamadas API de solo lectura y diseño de cambios basado en dry-run.

## Requisitos previos

- Poder preparar una cuenta de Google Ads, un proyecto GCP y un entorno Python
- Usar `/setup-google-ads` para avanzar por MCC, Developer Token, OAuth, cinco secretos y la verificación de conexión dry-run
- Se requiere aprobación OAuth en navegador, por lo que esta lección no puede completarse en modo no interactivo

## Objetivos

1. Comprender la jerarquía de Google Ads: MCC, cuenta, campaña, grupo de anuncios y keywords/anuncios
2. Confirmar los roles de Developer Token, OAuth Client, refresh_token y LOGIN_CUSTOMER_ID
3. Entender por qué empezar con llamadas API de solo lectura como listas de campañas y reportes GAQL
4. Ordenar patrones de cambio seguros con dry-run, creación PAUSED, logs JSON y puertas de confirmación
