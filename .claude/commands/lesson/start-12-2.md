## ⚠️ よくあるトラブルと解決方法

AskUserQuestion（AskQuestion）でトラブル内容を選んでもらい、押すだけで案内します。

**AskQuestionの設定例:**
```json
{
  "title": "トラブル内容を選択",
  "questions": [{
    "id": "trouble",
    "prompt": "当てはまる内容を1つ選んでください",
    "options": [
      {"id": "trouble_1", "label": "Database not found"},
      {"id": "trouble_2", "label": "プロパティが作成できない"},
      {"id": "trouble_3", "label": "フィルターが動作しない"},
      {"id": "trouble_4", "label": "日付の指定がうまくいかない"}
    ]
  }]
}
```


### トラブル1: 「Database not found」
**原因**: データベースIDが間違っている、またはアクセス権限がない
**解決プロンプト**:
```
以下を確認してください：
1. データベースが存在するページにインテグレーションが追加されているか
2. データベース名が正しいか
3. 親ページにインテグレーションが追加されているか
```

### トラブル2: プロパティが作成できない
**原因**: プロパティタイプの指定が間違っている
**解決プロンプト**:
```
Notion APIで対応しているプロパティタイプを確認してください：
- title, rich_text, number, select, multi_select, date, people, checkbox など
Select/Multi-selectの選択肢は事前に定義が必要です。
```

### トラブル3: フィルターが動作しない
**原因**: フィルター構文が間違っている
**解決プロンプト**:
```
Notion APIのフィルター構文を確認してください：
- 単一条件: {"property": "Status", "select": {"equals": "完了"}}
- 複数条件: {"and": [条件1, 条件2]}
```

### トラブル4: 日付の指定がうまくいかない
**原因**: 日付フォーマットが間違っている
**解決プロンプト**:
```
Notion APIの日付はISO 8601形式で指定してください：
- 日付のみ: "2024-01-15"
- 日時: "2024-01-15T09:00:00"
タイムゾーンも考慮してください。
```
