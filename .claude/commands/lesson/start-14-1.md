## ⚠️ よくあるトラブルと解決方法

AskUserQuestion（AskQuestion）でトラブル内容を選んでもらい、押すだけで案内します。

**AskQuestionの設定例:**
```json
{
  "title": "トラブル内容を選択",
  "questions": [{
    "id": "trouble",
    "prompt": "当てはまる内容を1つ選んでください",
    "options": [
      {"id": "trouble_1", "label": "テーマが決まらない・広すぎる"},
      {"id": "trouble_2", "label": "アウトラインが浅い・具体性がない"},
      {"id": "trouble_3", "label": "挿絵マーカーが生成されない"},
      {"id": "trouble_4", "label": "ファイルが保存されない"}
    ]
  }]
}
```


### トラブル1: 「テーマが決まらない・広すぎる」
**原因**: テーマの粒度が大きすぎて焦点が定まらない
**解決プロンプト**:
```text
テーマを絞り込むために、以下の3つの質問に答えてください：
1. 読者が一番知りたいことは何か？（1つだけ）
2. この記事を読んだ後、読者に何をしてほしいか？
3. 類似記事との差別化ポイントは？
これらをもとにテーマを再設定してください。
```

### トラブル2: 「アウトラインが浅い・具体性がない」
**原因**: テーマやターゲットの情報が不足している
**解決プロンプト**:
```text
アウトラインをより具体的にするために、各セクションに以下を追加してください：
- 具体的な事例やデータ（1つ以上）
- 読者への問いかけ（1つ）
- アクションアイテム（1つ）
```

### トラブル3: 「挿絵マーカーが生成されない」
**原因**: プロンプトで挿絵マーカー形式を指定していない
**解決プロンプト**:
```text
アウトラインに挿絵マーカーを追加してください。
形式: <!-- illustration: type=image|diagram, description="説明文" -->
各H2セクションに最低1つの挿絵マーカーを配置してください。
```

### トラブル4: 「ファイルが保存されない」
**原因**: outputディレクトリが存在しない
**解決プロンプト**:
```bash
outputディレクトリが存在するか確認し、なければ作成してください。
mkdir -p ~/ai-agent-camp/output
```
