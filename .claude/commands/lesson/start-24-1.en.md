# Lesson 24-1: Salesforce CLI Integration Introduction

## What You'll Do

Learn the basics of browser login, SOQL data retrieval, CSV bulk updates, and metadata retrieve/deploy using the **Salesforce CLI (`sf`)**.

## Prerequisites

- Be able to log in to a Salesforce org
- Have the `sf` CLI available
- Run `/setup-salesforce` first if setup is not complete

## Goals

1. Confirm the `sf org login web` and alias management flow
2. Search Account / Opportunity data with `/module-24-soql`
3. Understand the CSV insert / update / upsert workflow
4. Confirm the flow for `/module-24-metadata-retrieve` and `/module-24-metadata-deploy`
