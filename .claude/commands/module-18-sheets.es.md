# Módulo 18 — Sheets (Lección 4-5)

El usuario está trabajando con el material del curso "Módulo 18 - Integración de datos." **Mediante prompts,** utilice `sheets_ops.py` para asistir con la obtención por rango, exportación CSV y vista previa.

## Pasos

1. Confirmar el ID de la hoja de cálculo y el rango (preguntar al usuario si falta información).
2. Realizar operaciones equivalentes a `get` para obtención de datos, vista previa y exportación.
3. Para conjuntos de datos grandes, ajustar el fraccionamiento o la cantidad de filas de vista previa.
