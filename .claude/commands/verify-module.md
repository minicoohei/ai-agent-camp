# /verify-module [モジュール番号]

モジュール内の全レッスンの完了状況を自動チェックし、AI が総合評価とフィードバックを行います。

## 実行手順

### Step 1: 事実チェック実行

```bash
uv run python tools/verify_module.py --module $ARGUMENTS --json
```

### Step 2: AI評価

上記のJSON結果を読み取り、以下の3観点で評価してください。

#### 観点1: 成果物の存在と妥当性
- `outputs` の `exists` / `valid` を確認
- ディレクトリの場合は `file_count` を確認
- 不足・不正なファイルがあれば具体的に指摘

#### 観点2: チェックポイント達成度
- 成果物から推測できるチェックポイントは自動判定（ファイル存在 → 「生成できた」は達成と判断）
- 「理解した」「確認できた」等の主観的項目は **AskUserQuestion でユーザーに確認**

#### 観点3: 品質評価
- 成果物が存在する場合、実際にファイルを **Read** して内容を確認
- 画像ファイルは Read で表示して品質を確認
- JSON/HTML/Pythonファイルは構造・コード品質を確認

### Step 3: 結果を出力

以下のフォーマットで結果を表示してください:

```
## Module N: [モジュール名] 完了チェック結果

### サマリー
| 項目 | 結果 |
|------|------|
| 総合評価 | A / B / C / D |
| レッスン完了 | X / Y |
| 成果物 | X個確認 / Y個不足 |
| チェックポイント | X / Y 達成 |

### 評価基準
- **A**: 全レッスン完了、全成果物OK、品質良好
- **B**: 全レッスン完了、一部成果物に軽微な問題
- **C**: 主要レッスン完了、一部未着手
- **D**: 大部分が未完了

### レッスン別詳細
（各レッスンの成果物状況・チェックポイント達成度を表形式で表示）

### フィードバック
（不足項目の具体的な対処法・改善提案）

### 次のステップ
（全完了なら次モジュールへの案内、未完了なら再実施すべきレッスン）
```

### Step 4: 次のアクション

AskUserQuestion で以下の選択肢を提示:
1. 不足しているレッスンを実施する → 該当レッスンの `/start-X-Y` を案内
2. 次のモジュールに進む → `/verify-module N+1` を案内
3. 結果をJSONで保存する → `uv run python tools/verify_module.py --module N --json --output .cursor/module_verify_N.json`
