# チャネル戦略フレームワーク

## チャネル評価マトリクス

各チャネルを以下の5軸で評価（1-5点）:

| 軸 | 説明 |
|---|---|
| リーチ | ターゲットにどれだけ届くか |
| コスト効率 | CAC/投資対効果 |
| スピード | 効果が出るまでの時間 |
| スケーラビリティ | 拡大の容易さ |
| コントロール | 自社でコントロールできる度合い |

## チャネル選定プロセス

1. **ターゲットが居る場所を特定** — ペルソナの利用チャネルを調査
2. **3チャネルに絞る** — 初期は分散しすぎない
3. **90日テスト** — 各チャネルで90日運用して効果測定
4. **勝ちチャネルに集中** — ROI上位2つにリソース集中
5. **新チャネル追加** — 安定したら1つずつ追加

## コンテンツ再利用フロー

```
ロング動画 (YouTube)
  → 切り抜き (TikTok/Shorts/Reels)
  → テキスト化 (Note/Medium/ブログ)
  → 要約 (X スレッド)
  → 画像引用 (Instagram)
  → メルマガ素材
```

1つのコンテンツを最低5形態に変換して各チャネルに配信する。
